# FALSIFICATION — CAMS / CFP v5.0

> 修订说明：v5.0 把原先散落在正文里的 F1′–F8′ 改写为可执行判据表；F9′–F11′ 作为 v4.2 三目标升级的补充判据保留。本文只定义“什么结果算失败”，不报告任何实验结果。

## 0. Assumptions 与证据分级

- **A1 [设计]**：主实验先做 10³ 代理实现（2–4 周），再做 10⁴–10⁵；10³ 只检验协议是否值得扩展，不检验 0.1B 模型能力。
- **A2 [设计]**：主对照是 `A-skeleton`（保持三层骨架、去掉 H1–H4）；`A-noNS`、`A-discrete`、`dense-0.1B`、`B` 为辅助对照。`B` 是同预算集中式序列模型，不是 oracle。
- **A3 [假设]**：在 10³ 代理中，协方差门控事件足以形成可比较的 `T_π`；若事件数不足，判 `[TBD]` 而不是通过。
- **A4 [TBD]**：10⁴/10⁵ 的样本量、效应量和统计功效需由 10³ 的方差估计后预注册；本文不填虚假数字。
- **A5 [设计]**：显著性阈值 α=0.05；多重比较用 Holm 或 FDR；置信区间默认 95% bootstrap。
- **A6 [实测]**：当前仓库没有 10³/10⁴/10⁵ 实测数据；F6、V1–V3、Pareto 分数均为设计自检/rubric，不是实验测量。

证据标签：`[设计]` = 预注册的设计选择或阈值；`[假设]` = 待检验估计；`[实测]` = 有可复算数据与脚本。**没有 `[实测]` 的数字不得写成结果。**

## 4. 基线四段式（F1′ 的“可执行”要求）

每个基线必须写清四段，缺一段即 F1′ 失败：

1. **构造**：参数预算、层数、路由密度、训练步数、是否共享权重。
2. **预算对齐**：同 GPU-hour、同干预次数、同事件预算。
3. **阈值**：基线的确定/弃权阈值如何选；不得用测试集调参。
4. **检验**：单侧/双侧、置换次数、CI、多重比较修正。

## 5. 停止与报告规则

- **停止**：10³ 主判据 `p≥0.05` 即停止扩展，写“未通过 kill test”；`p<0.05` 但效应量低于预注册最小效应，也停止。
- **不停止**：`p<0.05` 且效应量达标，才进入 10⁴ 设计；不得用 100B 规模替代 10⁴。
- **报告**：每个 F 判据必须给出指标、CI、p、样本量、失败/通过；缺一项记 `[TBD]`，不得写成“通过”。
- **不可伪造**：[实测] 必须附原始 JSONL、哈希、复算命令；当前没有，故不得出现 [实测] 标签。
