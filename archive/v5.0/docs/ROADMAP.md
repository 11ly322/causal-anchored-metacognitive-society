# ROADMAP — CAMS / CFP v5.0

> 修订说明：v5.0 的路线图只到“可被第三方复现的 10⁴/10⁵ + 注册制试点”，不承诺产品化。所有预算为 `[假设]`/`[TBD]`，不是报价；所有 go/no-go 都是可失败的设计。

## 0. 总原则

- **证据优先**：G0 只有文档；G1 只有 10³ 代理；G2 才碰 10⁴/10⁵；G3 才谈真实部署。
- **不跳级**：G1 未过，不启动 G2；G2 未过，不拿 100B 规模当理由。
- **可停止**：每个阶段都有“停止条件”，不是“继续加算力”。
- **不伪造**：没有实测就写 `[设计]`/`[假设]`；预算未知写 `[TBD]`。

## 终止规则（全阶段）

1. **G1 失败**：停止该路线；允许一次机制修改后重跑；第二次失败则不再用 100B 补救。
2. **G2 失败**：只能写“未证明可扩展/未证明可部署”，不得写“接近理解”。
3. **G3 失败**：不得把 sandbox 结果包装成“已部署”。
4. **任何时候**发现伪造数据/泄漏/基线预算不对齐：结果作废，回到上一阶段。

## 不做什么

- 不做通用聊天产品；不与通用大模型比“能力”。
- 不做 100B 参数模型；100B 只是合同覆盖上限。
- 不做“多智能体社会模拟”演示；群体层只做局部稀疏路由与制度性局部扰动。
- 不用“人脑就是这样”作论证；生物类比只作为设计语言，不作证据。
