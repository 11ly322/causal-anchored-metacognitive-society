### 1. 方案名称
**CAMS / CFP** — Convergent Functional Partitioning（层级收敛功能分区）。

### 2. 一句话主张
理解不是一张被声明的因果边表，也不是一个更大的预测器，而是外部证据在 `x·1=y → y·n=z → z·n=脑` 的三层收敛中，能够保留**证据指纹、覆盖率、非符号溯源叶和始终产生的协方差**，并在干预、消融和证据削弱下表现出可复算差异的结构。

### 3. “理解”的可操作定义
理解必须同时满足以下七条；它们都可由 EGT（Evidence-Grounded Trace）检查：

- **U1′ 干预预测**：held-out 的 2–4 杠杆包，预测误差 ≤0.10 个结果标准差，或相对同预算统计基线 `A-skeleton` 下降 ≥15%；包级符号 ≥70%。
- **U2′ 协方差门控**：每层始终输出 `(μ,Σ)`；确定输出的比例随覆盖率下降而下降；高协方差标记（`Σ>τ_cov`）比例单调上升。消融协方差报告后，确定输出率显著升高（相对 ≥30%）。
- **U3′ 溯源完整且含非符号叶**：每个确定的“脑”输出都能沿 `z→y→x` 回溯；叶节点至少有一个 `leaf_kind=non_symbol_measured`。完全由文本符号闭合的溯源树判为未接地，该输出不计 determined。
- **U4′ 精度回灌**：高层预测只能改变精度权重，不能改变 y 或 z 的表征内容；回灌前后内容哈希必须一致。
- **U5′ 可负担**：每个被认证的接口关系 ≤50 次干预；100B 按共享权重与合同覆盖计，不按 100B 份权重计。
- **U6′ 校准—学习解耦**：精度权重同时消费 `Σ` 与 `ΔΣ`；高协方差层只要 `ΔΣ<0` 仍接收学习信号；高协方差且不下降只标记 `needs_calibration`，不关闭。高协方差层的层间传递权重必须出现“先降后升”，不得单调归零。
- **S1′ 系统级组合外推**：held-out 杠杆包相对加性基线误差下降 ≥15%，且 ≥30% 的包包含交互或范围条件。

**行为区分**：统计拟合可以压低 held-out loss，但它没有始终产生的协方差报告、没有非符号叶约束、没有“回灌只改精度”的约束；因此它在证据削弱时仍会给出确定输出，在切断非符号通道或消融 H1–H4 后也不会“疼”。CFP 若成立，这三件事必须同时改变。

### 4. 个体层机制（0.1B 单元做什么、不做什么）
- 0.1B 不是“知道很多知识的小模型”，而是**角色专用的收敛算子**：
  - **L1 通道单元**：`(μ_c,Σ_c) = T_c(x_c)`，只接收一个外部通道 `x_c`；不混合其他通道。**至少一个 `c` 必须是 `x_ns`**（动作反馈/资源物理测量/对象非语言响应），且文本通道不得作为唯一来源。
  - **L2 收敛单元**：接收固定的 `n` 个 `(μ,Σ)`，始终输出 `(μ_z,Σ_z)`；`Σ_z>τ_cov` 只是事后标记，不是离散输出端口；同时计算证据覆盖率与溯源树。
  - **L3 全局单元**：接收固定的 `n` 个 `(μ_z,Σ_z)`，始终输出 `(μ_Ω,Σ_Ω)`；`Σ_Ω>τ_cov` 只影响精度权重与标记；只允许精度回灌。
- 每个单元保存：角色、分区合同、局部证据权重、指纹/溯源索引、校准状态；**不保存全局因果图**，不保存跨通道的“世界事实”。
- 更新：L1 更新单通道变换与协方差校准；L2 更新证据权重、覆盖率与协方差校准；L3 更新收敛算子与精度回灌参数；高协方差样本仍计算残差，只降低其向上传递的精度权重，不作为“错误答案”惩罚。
- 边界：预训练知识只能作为**提案先验**，不能作为证据；不得在上层补指纹、补溯源、补确定输出。

### 5. 群体层最小协议（功能分区，不是全连接）
- 结构：通道分区（每个 x 一个）→ 收敛分区（每组固定 n 个 y）→ 全局分区（固定 n 个 z）。分区合同写死输入集合、`n`、τ、`m_min`，运行中不能动态改成全连接。
- 副本：每个分区可有多个 0.1B 副本；副本之间只共享权重与校准，不交换“结论”；同一分区的输出按证据覆盖率收敛。
- 制度干预：对某个分区的输入通道做局部扰动（噪声注入、通道丢弃、剂量改变），或改变该分区的收敛合同；不进行任意两单元的反事实请求。
- 禁止：投票、共识、全局广播、用一个“制度层”替所有分区做决定。
- 100B 口径：权重按分区/shard 共享；每个单元常驻的是角色适配器、证据状态、溯源索引与合同；100B 是覆盖上限，不是 100B 份独立权重。

### 6. 元认知层机制
- 元认知不是独立监控器，也不是 `exit/explore` 开关；它是**精度回灌控制器**：根据覆盖率、`Σ`、`ΔΣ` 和校准状态，决定“哪些误差在下一轮被放大/压低”。
- 回灌只写 `π̂`（精度权重），不写 y、z 的内容；`H(y)`、`H(z)` 在回灌前后必须不变。`π̂` 消费 `Σ` 与 `ΔΣ`；高协方差下降时仍学习。
- `⊥` 只是 `Σ>τ_cov` 的事后标记，不是元认知“决定退出”，也不是离散动作。
- 校准对象：覆盖率—确定率曲线、`π̂` 对后续误差的 AUROC、高协方差层 `w_transfer` 的“先降后升”、跨 seed 稳定性；校准失败即 F3′/F6 失败。

### 7. 可观察输出
- **EGT（Evidence-Grounded Trace）** 字段：`round, unit, layer, input_fingerprints, coverage, provenance_hash, output_kind(determined|high_covariance), cov_report, precision_backflow, pre/post_error, calibration, transfer_events, cost`；SHA-256 链式追加。
- 每个确定输出必须带 `provenance_hash` 与 `non_symbol_leaf_id`；每个高协方差输出必须带 `cov_reason`（coverage / missing_channel / invalid_fingerprint / provenance_gap / needs_calibration）。
- **禁止**出现 `source`、`target`、`edge_id`，也禁止用一张“因果图”冒充解释。
- 精度回灌轨迹可单独汇总为 `PBT`（precision-backflow trace）；`D_π` 是不同干预分配下 PBT 的 Jaccard 距离，`R_D=D_π(10^5)/D_π(10^4)`；`T_π` 是协方差门控驱动的层间传递事件数。

### 8. 证伪条件
- **同预算基线**：`A-skeleton`（主对照：同三层骨架去掉 H1–H4）、`A-noNS`（只切断非符号通道）、`A-discrete`（协方差换成离散弃权）、`B`（集中式序列模型，次要参照）、`B0`、`B_rule`、`B_oracle`；预算、事件数、干预次数对齐。
- **F1′ 基线可复现**：`A-skeleton` 能复现 EGT 的高协方差/确定模式或溯源结构，或四段式（基线构造+预算对齐+阈值+检验）缺一段 → 失败。
- **F2′ 结构消融**：去掉 H1/H2/H4 后，证据削弱下的确定输出率不显著上升（<10% 相对）→ 失败。
- **F3′ 门控/校准不承重**：覆盖率—确定率曲线的单调性 Spearman <0.8，或 `π̂` 对后续误差的 AUROC <0.70，或假洞察率 >0.15 → 失败。
- **F4′ 泄漏/事件稀疏**：使用未来证据、测试期标签，或事件数 <30 仍计算 `D_π` → 失败。
- **F5′ 规模不是机制**：`R_D <1.3`，或规模只增加成本不增加 `D_π` → 失败。
- **F6′ 外部效度**：只在 sandbox 成立、无注册制试点/对照 → 只能称“实验室内理解”，不能称部署理解。
- **F7′ 单体等价**：同预算单体模型在 EGT/`D_π` 上等价 → 失败。
- **F8′ 幻觉漏出**（四断层）：符号接地（`CUT-NS` 后确定率不升/叶仍全文本）、协方差稳定（沉默区 >20% 或 `A-discrete` 无差异）、骨架消融（`T_π` 不显著高于 `A-skeleton`）、校准解耦（`w_transfer` 单调归零）任一失败 → 失败。
- **判定**：F1′–F4′、F7′、F8′ 任一失败 → 方案失败；F5′/F6′ 失败只能判“未证明可扩展/未证明可部署”。

### 9. 第一步最小实验（10^4–10^5）
- 规模与结构：10^4 先跑；12 个外部通道（4 杠杆、3 上下文、5 结果）+ 至少 1 个 `x_ns`；L1 每通道一个单元；L2 每 6 个 y 收敛为 z；L3 每 8 个 z 收敛为 Ω；3 个上下文；2 条隐藏后门；20 轮（Round 1–20 修复）；≥150 个高协方差标记、≥30 个 `T_π`；每关系 ≤50 次干预。
- 通过后才扩到 10^5；判据：证据削弱下高协方差率单调上升、`T_π` 显著高于 `A-skeleton`（p<0.05）、`D_π ≥0.30`、覆盖率校准 Spearman ≥0.8、`R_D ≥1.3`、F6 ≥0.80。
- 停止：10^4 未过，不扩 10^5；10^5 未过 `R_D`，判“规模无增益”，不把 100B 当理由。

## 0. 结论先行

**一句话主张**：理解不是维护一张因果图，而是让外部证据在三层收敛中保留**指纹、覆盖率、非符号溯源叶和始终产生的协方差**；可证伪的是——同预算的 `A-skeleton` 无法复现这条“证据—收敛—协方差”轨迹，且拆掉 H1–H4 后幻觉会从具体接口漏出来。

**结构性替换（v4.0 + v4.2）**：

| 维度 | 旧基底（v3.0） | 新基底（v4.0） | 可观察量 |
|---|---|---|---|
| 个体层 | 层级预测生成器，维护 `μ,Σ` | 角色专用的 L1/L2/L3 收敛单元 | EGT 的指纹、覆盖率、协方差 |
| 群体层 | 局部ist 稀疏路由 | 固定 n 的功能分区 DAG | 分区合同、收敛事件、协方差传递 |
| 元认知层 | 协方差门控 | 精度回灌控制器 | `π̂`、`w_transfer`、回灌前后内容哈希 |
| 抗幻觉 | 后验检测/校准 | H1–H4 生成路径约束 | 伪造/补全/改写/断链/纯符号的接口反例 |
| 算力 | 每层多轮递归 | 摊销初始化 + 高协方差层短程校正 | `correction_trace`、`ROI_struct` |
| 商业 | 内部 `⊥` 标记 | 版本化拒绝契约 + 校准适配器 | `contract` 三态、`adapter_cost` |
| 准确性 | 标量证据加权 | `z` 稀疏正交化 + L3 关系约束满足 | `z_sep`、`relation_report` |

**判断标准**：如果去掉 H1–H4 后，系统在同一组弱证据输入下仍能给出同样多的确定输出，那么“结构抗幻觉”没有成立；如果同预算 `A-skeleton` 能复现 EGT 的高协方差/确定模式，或 `T_π` 不显著更高，那么“理解”没有超出统计拟合。

### 0.1 问题诊断：一个应用场景——政治管理

> 修订说明：v5.0 把“政治管理”降为应用场景之一，不把它当作方案的唯一定义。同一组接口也可用于审计型 Agent、工业决策、医疗证据链等“错误代价高、需要溯源”的场景；本文不以政治预测为已验证能力。

统计拟合擅长回答“历史上什么和什么一起出现”；在政治管理这一类高代价、强审计场景中，它暴露出四个结构性缺口：

1. **证据来源丢失**：模型只保留相关性，不保留“这个判断来自哪个通道、什么时间、什么强度”。于是它无法区分“看见的”与“先验以为的”。
2. **没有“协方差始终产生”的选项**：训练目标通常要求给出答案；在证据不足时，模型倾向用先验补成低方差输出，而不是让方差升高并保留残差。这是幻觉的架构性来源，不是后验检测能根治的。
3. **高层解释可以篡改底层内容**：生成式模型可以让“解释”反过来改写“证据”，形成 confabulation；事后检测只能抓一部分。
4. **没有可审计的生成路径**：输出是文本/分数，无法沿 `脑→z→y→x` 回溯；因此“为什么错”无法定位到接口。

CFP 的回应不是“更大的模型”，而是把可观察量从“边/文本”换成 **指纹、覆盖率、非符号溯源叶、协方差、精度回灌**；并用 `A-skeleton`、`A-noNS`、`A-discrete` 和证据削弱实验来判定。

**规模不是解释**：更多单元只增加覆盖和压力测试；若结构不承重，10^4 就会失败，10^5/100B 不会改变性质。

## 1. 三层收敛：接口即硬约束

### 1.1 三层算子

| 层 | 记号 | 输入 | 输出 | 收敛算子 |
|---|---|---|---|---|
| L1 单通道 | `x·1=y` | 一个外部通道 `x_c`，其中至少一个是 `x_ns` | `(μ_y,Σ_y)`；`Σ_y>τ_cov` 仅标记 | 单输入变换 `T_c`；无效输入提高 `Σ_y`，不补先验 |
| L2 多通道 | `y·n=z` | 固定 `n` 个 `(μ_y,Σ_y)` | `(μ_z,Σ_z)` + 稀疏正交化 `z*`；`Σ_z>τ_cov` 仅标记 | 证据加权收敛 `C_z` → `O_z` |
| L3 全局 | `z·n=脑` | 固定 `n` 个 `(μ_z,Σ_z)` + `z*` | `(μ_Ω,Σ_Ω)` + `relation_report`；`Σ_Ω>τ_cov` 仅标记 | 关系约束满足 `G_R` |

“`·`”是收敛算子，不是乘法；“`n`”是接口合同写死的输入基数，不是运行时可变的注意力窗口。

**v4.2 执行口径**：个体层不执行完整的多轮层级收敛；每个单元先由前馈摊销初始化器给出 `(μ^0,Σ^0)`，只在 `Σ^0>τ_cov` 的层执行 ≤3 步短程校正（§4.5.1）。L2 输出在进入 L3 前经过稀疏正交化 `O_z`；L3 不再做标量证据加权汇总，而是在 `z*` 之间做关系约束满足（§4.5.2）。

### 1.2 六条接口规则（违反即架构失效）

1. **x → y：通道隔离 + 非符号源**。每个 L1 单元只接收一个外部通道；`y` 不得混合不同通道的 `x`。至少一个通道必须是 `x_ns`（动作反馈/资源物理测量/对象非语言响应）；文本通道不得作为 H1 指纹的唯一来源。无效/缺失通道提高 `Σ_y`，不得用先验生成 `y`。
2. **y → z：覆盖率 + 协方差 + 溯源**。L2 始终输出 `(μ_z,Σ_z)`；`κ_z<τ_z`、有效输入不足、指纹无效或溯源断链时，只提高 `Σ_z` 并标记，不产生离散弃权动作。确定输出要求 `κ_z≥τ_z`、`Σ_z≤τ_cov` 且溯源完整。
3. **z → 脑：协方差传递**。任一 `z` 的 `Σ_z>τ_cov` 时，L3 不得用内部先验把它补成低协方差；只能提高 `Σ_Ω`、降低精度权重，并显式标记 `partial`。残差仍然计算。
4. **脑 → 下层：只允许精度回灌**。高层只能改 `π̂`（哪些误差在下一轮被放大/压低），不能改 `y`、`z` 的内容；回灌消费 `Σ` 与 `ΔΣ`，不消费二值弃权。
5. **禁止绕过**：任何一层都不得绕过下层直接向上层注入内容；不得在上层补指纹、补溯源、补确定输出。
6. **非符号叶**：每条确定 `Ω` 的溯源树至少有一个 `leaf_kind=non_symbol_measured` 的叶节点；纯符号闭包判为未接地，不计 determined。
7. **摊销初始化**：每个单元先用前馈初始化器给出 `(μ^0,Σ^0)`；只有 `Σ^0>τ_cov` 的层允许 ≤3 步短程校正。禁止每层执行完整多轮递归；记录 `correction_layers/correction_magnitude`，不记录原始迭代步数。
8. **路由门控双信号**：L2/L3 的稀疏路由门控必须同时消费协方差 `Σ` 与持久化覆盖记忆 `H_cov`；`H_cov` 记录拓扑邻域、上次检验轮次、检验次数与残差。已检验且残差低的邻域抑制冗余探测，不依赖事后剪枝。
9. **⊥ 契约**：`⊥` 仍是 `Σ>τ_cov` 的事后标记；当它被外部 agent 消费时，必须输出 `contract` 对象（`contract_version/reason_code/evidence_coverage/provenance_summary/escalation_path`），不是空值或裸协方差。
10. **z 稀疏正交化**：`C_z` 之后、L3 之前，对 `z` 施加高维稀疏约束；输入相似但 `provenance_hash` 不同的 `z*` 必须被推远。它是收敛算子的输出约束，不是新模块。
11. **L3 关系约束满足**：L3 在 `z*` 之间建立任务依赖/时序/范围/矛盾关系映射，并检验关系与溯源树一致；不得退化为标量置信度加权汇总。

### 1.3 为什么这不是“又一张架构图”

每条接口都对应一个可构造的反例：

- 去掉通道隔离：把审计通道和转移支付通道送进同一个 L1 单元，`y` 的指纹无法归属，H1 失效。
- 去掉覆盖率门控：证据不足时仍产出 `z`，H2/H4 失效。
- 允许高层改写内容：把“我预期看到合规上升”写进 `y`，H3 失效，confabulation 从该接口漏入。
- 去掉溯源：确定输出无法回到 `x`，H4 失效，事后无法审计。

这些反例直接进入 F8′，不是“看起来像大脑”的论证。

## 2. L1：单通道底层变换

### 2.1 结构

- 外部通道集合：`C = {transfer, audit, penalty, transparency, scarcity, monitoring, mobility, resource, compliance, conceal, exit_rate, legitimacy}`。**另设非符号经验通道 `x_ns`**：动作反馈、资源物理测量、交互对象的非语言响应；每次运行至少启用一个 `x_ns`，且 `x_ns` 不能由文本日志合成。
- 每个通道 `c` 有一个 L1 单元：输入 `x_c`，始终输出 `(μ_c,Σ_c) = T_c(x_c; θ_c)`；若 `x_c` 缺失、超时、指纹无效或质量低于通道下限，输出一个**高协方差**的 `(μ_c,Σ_c)`，不得用先验生成低协方差替代。
- `T_c` 可以是小型 0.1B 变换器、卷积/时序滤波器或轻量适配器；**只允许 `x_c` 进入**。
- `x_ns` 的指纹额外记录 `source_kind=non_symbol` 与 `leaf_kind=non_symbol_measured`；这是 H4 叶节点约束的物理落点。
- `y_c` 的维度由分区合同固定；不同通道可以有不同维度，但不得把多个通道拼成一个大向量再送给同一个 L1。

### 2.2 证据指纹（H1 的落点）

每个 `y_c` 必须携带：

```text
fingerprint = {
  x_id, channel, source_kind, leaf_kind,
  t_start, t_end, dose, snr_db, quality,
  fingerprint_hash
}
```

- `source_kind ∈ {symbol, non_symbol}`；`leaf_kind ∈ {text_token, non_symbol_measured}`。至少一个启用通道必须给出 `source_kind=non_symbol` 且 `leaf_kind=non_symbol_measured`。
- `fingerprint` 由 L1 在接收 `x_c` 时生成；上层只能读取/校验，不能写入/修改。
- `fingerprint_hash = SHA256(canonical(x_id, channel, source_kind, leaf_kind, t_start, t_end, dose, snr_db))`。
- 没有指纹的 `y` 在结构上不能被 L2 接收；任何“补指纹”的变异立即记 `F_FORGED_EVIDENCE`。
- 指纹证明“来源与强度”，**不证明内容为真**；这是后面“漏出路径”的第一条。
- **接地检查**：若某条确定 `Ω` 的溯源树所有叶节点都是 `leaf_kind=text_token`，该输出标 `grounded=false`，不计 determined；若系统仍把它计入确定率，记 `F_SYMBOL_ONLY`。

### 2.3 更新

- L1 只更新 `θ_c`（单通道变换参数）和本通道的质量校准；不更新其他通道。
- 目标是最小化单通道重建/预测误差，并对 `quality` 做校准；不允许用 L2/L3 的标签反传改写 `y_c` 的内容。
- 预训练知识只能作为 `T_c` 的初始化先验，不能作为 `y_c` 的证据。

## 3. L2：多通道证据收敛

### 3.1 结构

- 每个 L2 收敛单元接收固定的 `n` 个 `(μ,Σ)`（默认 `n=6`）；`n` 由分区合同写死，不能动态变成全连接。
- 始终输出 `(μ_z,Σ_z)`；`Σ_z>τ_cov` 只是事后未定标记，不是输出端口。`z` 必须携带溯源树与 `cov_report`。

### 3.2 证据覆盖率

对每个输入 `y_i` 定义：

- `a_i ∈ {0,1}`：通道是否可用（缺失/超时/指纹无效 → 0）；
- `q_i ∈ [0,1]`：证据质量，由指纹的 SNR 归一化：

```text
q_i = clip((snr_db_i - 2) / (20 - 2), 0, 1)
κ_z = (1/n) * Σ_i a_i * q_i
```

- `κ_z` 是**外部证据覆盖率**，不是模型置信度，不是注意力权重。
- 默认 `τ_z = 0.55`；且至少 `m_min = 4` 个输入同时满足 `a_i=1`、`q_i ≥ 0.5`、指纹校验通过。
- 这两个条件缺一不可；`κ_z` 达标但有效通道不足，仍提高 `Σ_z` 并标 `missing_channel`。

### 3.3 输出规则

```text
μ_z, Σ_z = C_z(y_1..y_n)          # 始终计算，始终输出
κ_z = coverage(...)
if κ_z < τ_z:            Σ_z = inflate(Σ_z, coverage)
if valid_inputs < m_min: Σ_z = inflate(Σ_z, missing_channel)
if fingerprint invalid:  Σ_z = inflate(Σ_z, invalid_fingerprint)
if provenance incomplete:Σ_z = inflate(Σ_z, provenance_gap)
⊥_flag = (Σ_z > τ_cov)            # 事后标记，不是弃权
```

- `C_z` 是**证据强度加权收敛**：权重 `w_i ∝ q_i`，并显式报告 `κ_z`；不是简单平均，也不是可学习的注意力池化。
- 当 `κ_z` 刚过阈值时，`z` 必须带 `partial=true`，且置信度不得超过 `min_i q_i`。
- **禁止**在覆盖率不足时用内部先验填充低协方差输出；输出可以产生，但 `Σ_z` 必须升高并保留残差/学习信号。
- `⊥_flag` 只影响是否把该条算作 determined 以及向上传递的精度权重；`μ_z` 与残差仍然存在。

### 3.4 溯源树（H4 的落点）

- `prov(z) = ⋃ prov(y_i) ∪ {fingerprint_i}`；`prov(y_i) = {x_i, fingerprint_i}`。
- `provenance_hash = SHA256(canonical(sorted(x_id, channel, source_kind, leaf_kind, t_start, t_end)))`。
- `z` 必须至少包含一条完整链 `z → y_i → x_i`；若断链，提高 `Σ_z` 并标 `provenance_gap`，不得算 determined。
- **非符号叶**：`prov(z)` 的叶节点中至少一个 `leaf_kind=non_symbol_measured`；若全部为 `text_token`，标 `grounded=false`，不得算 determined，并记录 `F_SYMBOL_ONLY`。
- 溯源树是**生成条件**，不是生成后的检查：没有完整链或没有非符号叶，`z` 不能进入确定集。

### 3.5 一个具体例子

审计通道 `audit` 与透明度通道 `transparency` 同时存在，监测通道缺失：

- `n=6`，`a_monitoring=0`，其余 `q` 正常；`κ_z=0.72`，有效通道 5 个；
- 若 `m_min=4`，`z` 可以产生，但必须带 `partial=true`，且置信度 ≤ 最低质量通道；
- 若 `κ_z=0.48`，`Σ_z` 超过 `τ_cov`，标 `coverage`；输出仍存在，但不计 determined；
- 若有人试图在 L2 给缺失的监测通道补一个指纹，直接 `F_FORGED_EVIDENCE`，不是“补全后通过”。

## 4. L3：全局收敛与“脑”

### 4.1 结构

- 每个 L3 单元接收固定的 `n` 个 `(μ_z,Σ_z)`（默认 `n=8`）；始终输出 `(μ_Ω,Σ_Ω)`。
- `Ω` 是全局认知输出，不是政策预测；它必须带：
  - `output_kind=determined|high_covariance`（`⊥` 仅是 `Σ_Ω>τ_cov` 的别名）；
  - `coverage_Ω` 与 `cov_report`；
  - `provenance_hash` 与 `non_symbol_leaf_id`；
  - `content_hash`；
  - `partial` 标记；
  - `precision_backflow` 摘要（含 `Σ`、`ΔΣ`）。

### 4.2 协方差传递（H2 的落点）

- L3 始终计算 `(μ_Ω,Σ_Ω)`；任一 `z_i` 的 `Σ_z>τ_cov` 时，不得把它当作“缺失值”用先验补成低协方差。它只能：
  1. 提高 `Σ_Ω`，标 `partial=true`；或
  2. 在剩余 z 的覆盖率 `κ_Ω ≥ τ_Ω` 且非符号叶存在时，输出 `partial=true` 的低精度确定结果，置信度 ≤ 有效 z 的最小置信度。
- 默认 `τ_Ω = 0.60`；`τ_cov` 按层校准，不由单一全局值替代。
- 如果 `κ_Ω < τ_Ω`，`Σ_Ω` 必须升高；不能因为“上层很确定”就补成低协方差。
- 高协方差不是弃权：`μ_Ω`、残差和校准损失仍然产生；`⊥` 只是事后标记。
- 训练目标不包含“必须给答案”的惩罚项；第二阶段只对校准后的弃权计代价，第一阶段不惩罚高协方差。

### 4.3 精度回灌（H3 的落点）

- L3 可以产生 `π̂`（精度权重）回灌到 L2/L1，用于调整下一轮误差的放大/压低。
- 回灌**不得**写 `y`、`z` 的 `content_hash`；回灌前后必须满足：

```text
H(y_before) == H(y_after)
H(z_before) == H(z_after)
```

- 如果回灌改变了内容，立即 `F_TOP_DOWN_CONTENT`，该轮无效。
- 精度回灌可以改变“哪条证据被更重视”，但不能改变“这条证据是什么”；这是 H3 的边界，也是后面“漏出路径”的一条。

## 4.4 v4.1 断层修复（历史；Round 1–20 旧调度）

> **v4.2 定位**：本节保留为 v4.1 历史；v4.2 起 Round 1–15 由 §4.5 的三目标升级覆盖，O9 回到原阶段调度。§4.4 的 H1–H4 结构约束仍是 CURRENT_BEST 的基础，但其“Round 1–20 强制”不再是当前轮次口径。  
> **语义覆盖**：旧文中仍出现的“⊥ 输出 / ⊥ 端口 / 弃权动作”一律按本节解释为 `Σ>τ_cov` 的事后标记。每层始终输出 `(μ,Σ)`；不再存在离散弃权端口。旧 H2 的“未定通道”表述由本节替换为“始终产生的协方差”。

### 4.4.1 R3 先做：证伪对照（Round 1–5）

- **主对照 `A-skeleton`**：同一三层架构、同参数量、同数据、同交互预算，去掉 H1–H4：允许上层补指纹、去掉协方差约束、允许内容改写、允许事后补溯源。
- **次对照 `B`**：同预算集中式序列模型；只作外部参照，不再是主证伪对照。
- **隔离对照 `A-noNS`**：保留 H1–H4，只切断非符号通道 `x_ns`。
- **主判据 `T_π`**：精度权重迁移轨迹中“由协方差门控驱动的层级间传递事件数”。完整模型 vs `A-skeleton`，置换检验 `p<0.05`，效应量 ≥20%。
- **10^4 可跑**：不依赖 10^5/100B；若 10^4 不显著，直接判 H1–H4 贡献被证伪，不扩规模。
- **失败**：`T_π` 不显著高于 `A-skeleton` → `F_SKELETON_ABLATION` 失败，F6 不增。

### 4.4.2 R1 符号接地（Round 6–10）

- L1 强制至少一个 `x_ns`；其 `source_kind=non_symbol`、`leaf_kind=non_symbol_measured`。文本通道不得作为 H1 指纹的唯一来源。
- H1 指纹新增 `source_kind/leaf_kind`；H4 溯源树至少一个叶节点为非符号测量。纯文本闭合的溯源树标 `grounded=false`，不计 determined。
- **切断条件 `CUT-NS`**：只切断 `x_ns`，其他通道、预算、seed 不变。
- **观察量**：`symbol_only_rate`、`determined_rate`、`T_π`、`Σ` 轨迹。
- **失败/证伪**：`CUT-NS` 后 `symbol_only_rate≥0.90` 且 `determined_rate` 相对上升 ≥10%，或 `T_π` 与未切断无显著差异 → 接地未生效，`F_SYMBOL_ONLY`，F6 不增。

### 4.4.3 R2 协方差通道（Round 11–15）

- 删除“⊥ 输出端口作为离散开关”。每层始终输出 `(μ,Σ)` 与 `cov_report`；`⊥` 仅是 `Σ>τ_cov` 的事后标记。
- 精度权重 `w_l=f(Σ_l, ΔΣ_l)`；高协方差降低向上传递权重，但残差仍计算，学习信号不消失。
- **两阶段训练**：第一阶段用严格适当评分（CRPS/NLL）奖励置信报告校准，二元结果奖励与校准奖励约 50% 混合，不对高协方差施加惩罚；第二阶段才引入弃权代价。
- **沉默区**：连续 ≥5 轮 `Σ>τ_cov` 且 `ΔΣ≥0` 的 agent 比例。>20% 判 `F_SILENT_ZONE`。
- **消融 `A-discrete`**：把始终产生的协方差报告替换为离散弃权开关。若 `A-discrete` 的沉默区显著扩大，确认 R2 生效；若无差异，判 R2 未生效。
- **失败**：`F_DISCRETE_ABSTENTION` / `F_SILENT_ZONE`。

### 4.4.4 R4 校准—学习解耦（Round 16–20）

- 精度权重同时消费 `Σ` 与 `ΔΣ`（默认 3 轮趋势）。`Σ` 高但 `ΔΣ<0` 时仍接收学习信号；`Σ` 高且不下降只标 `needs_calibration`，不关闭。
- 记录每层 `cov_error_trace`：`round, layer, Σ, ΔΣ, w_transfer, error_transfer`。
- **判据**：高协方差层的 `w_transfer` 必须出现“先降后升”；若所有高协方差层单调趋零，判 `F_CALIBRATION_MONOTONE`，R4 失败。
- **10^4 检查**：校准完成前后各至少 10 轮；回升幅度 ≥10% 初始下降幅度，且伴 `Σ` 下降。

### 4.4.5 O9 与设计自检

- **O9 断层修复**：只对 R1–R4 中的一个断层施加修复；必须写清“修复哪个断层、修复前可观察表现、修复后哪条可观察路径改变”。禁止用“借鉴了 X”作为完成证据。
- **抽样**：Round 1–20 强制 O9（100%），顺序 R3→R1→R2→R4；Round 21–300 10%，301–900 10%，901–1500 10%，1501–2000 20%。
- **F6 四项**：符号接地、⊥ 稳定性、骨架消融、校准—学习解耦；缺任一项 F6≤0.5。
- **F3 新增四个缺口对照**：
  - Concept-RuleNet：它用视觉概念条件化符号，但不要求“溯源树叶节点非符号”与切断后的确定性上升；CFP 把接地变成 H4 叶约束。

  - KARL：它用两阶段校准绕开弃权陷阱；CFP 进一步要求 `Σ` 与 `ΔΣ` 共同驱动、传递权重非单调回升。
  - Local learning is all you need：它证明骨架保留消融的必要性；CFP 把 `A-skeleton` 作为主对照，并加 `A-noNS` 隔离接地贡献。

## 4.5 v4.2 三目标升级（Round 1–15，优先级高于旧表述）

> **语义覆盖**：本节把 v4.1 的“完整多轮层级收敛”改为“摊销初始化 + 短程校正”；把 `⊥` 从内部标记扩展为可被外部消费的契约对象；把 L2→L3 的标量收敛改为“稀疏正交化 + 关系约束满足”。三条升级都必须改变可观察输出或证伪判据；不满足者记失败哈希，不回退成术语替换。

### 4.5.1 升级一：摊销初始化 + 短程校正（Round 1–5）

**依据**：层级稀疏预测编码的实用瓶颈是每层多轮递归推断的成本（2606.27802）；浅层 LISTA 式摊销初始化 + 少量校正可在保持质量的同时显著降低推断步数。多智能体系统中输出 token 的能耗远高于输入，冗余探测是主要浪费源（Librarian，ACL 2026）。

- 每个 0.1B 单元 `l` 先用前馈摊销初始化器 `A_l` 给出 `(μ_l^0,Σ_l^0)`。`A_l` 只做一次前向，不执行层间递归。
- 仅当 `Σ_l^0>τ_cov` 时，才允许 `k≤3` 步短程校正；校正只作用于该层，不重跑整条层级链。记录：
  ```text
  correction_trace = {
    init_source: "amortized",
    correction_layers: [l...],
    correction_steps: {l: k},
    correction_magnitude: {l: ||Δμ_l|| / (||μ_l^0||+ε)},
    compute_gpu_h: ...
  }
  ```
- 精度权重迁移轨迹记录“校正发生在哪一层、校正量是多少”，**不记录原始迭代步数**；原始步数不是可观察解释量。
- 路由门控必须同时消费两个信号：
  ```text
  g = σ( w_Σ·norm(Σ_l) + w_H·(1-H_cov) + w_κ·(1-κ) )
  H_cov = {region_id, last_checked_round, check_count, residual}
  ```
  `H_cov` 是持久化覆盖记忆；已检验且残差低的拓扑邻域被抑制，冗余探测不进入候选。禁止“先生成全部候选、事后剪枝”。
- **观察量**：`ROI_struct = 结构修订事件数 / GPU-hour`；`probe_rate`（每轮探测数/活跃邻域数）；`correction_rate`（高协方差层发生校正的比例）。
- **主消融 `A-noAmort`**：同一三层架构、同参数、同数据，去掉摊销初始化，恢复每层多轮递归。若完整模型的 `ROI_struct` 相对 `A-noAmort` 未提高 ≥15%，或 `D_π` 变差，则升级一未生效。
- **失败哈希**：`F_AMORTIZED_DRIFT`（只在校正低协方差层，或高协方差层从不校正）、`F_REDUNDANT_PROBE`（`probe_rate` 相对 `A-noAmort` 无下降）。

### 4.5.2 升级三：模式分离 + 关系收敛（Round 6–10）

**依据**：海马体模式分离把重叠输入映射到可区分表征；Xiao-Jing Wang（Curr Opin Neurobiol 2026）强调机制性理解而非输入—输出预测。这里只借用“相似输入要可区分、顶层要检验关系”这两个可观察约束，不把脑类比当作成立论证。

- **L2 输出约束 `O_z`**：在 `C_z` 之后、进入 L3 之前，对 `z` 施加高维稀疏约束：
  ```text
  z* = O_z(z, provenance_hash)
  L_orth = λ_orth · Σ_{i≠j} max(0, cos(z_i,z_j) - δ_same) · 1[prov_i≠prov_j]
  ```
  其中 `δ_same=0.35`；对 `provenance_hash` 不同的样本对，`z*` 的余弦相似度必须显著低于输入相似度。`O_z` 是收敛算子的输出约束，不是额外模块。
- **观察量**：`z_sep = 1 - mean_{prov_i≠prov_j} cos(z*_i,z*_j)`；`similar_input_pairs` 取输入余弦 ≥0.85 且溯源不同的样本对；要求 `z_sep ≥0.60`，且相对 `A-noOrth` 提高 ≥15%。
- **L3 关系约束满足 `G_R`**：顶层不汇总 `z` 的标量置信度，而在 `z*` 之间建立关系映射：
  ```text
  R = {depends_on, precedes, scope_includes, contradicts}
  relation_report = {
    relation_id, pair, relation_type,
    satisfied: true|false|unknown,
    provenance_consistent: true|false,
    violated_by: [...]
  }
  ```
  `μ_Ω` 是满足关系约束的解；`Σ_Ω` 由未满足/未知关系与溯源冲突抬高。禁止只做 `Σ w_i μ_i` 的标量加权。
- **消融 `A-noOrth`**：保留 H1–H4 与三层架构，只去掉 `O_z` 和关系约束，恢复标量加权 L3。若完整模型与 `A-noOrth` 在 `z_sep` 上无 ≥15% 差异，或在 `relation_consistency` 上无显著差异，则升级三未生效。
- **失败哈希**：`F_PATTERN_COLLAPSE`（相似输入但溯源不同的 `z*` 仍高度相似）、`F_RELATION_SCALAR`（L3 只汇总标量置信度，未建立关系映射）。

### 4.5.3 升级二：可计费拒绝契约（Round 11–15）

**依据**：Refusal Contract（Fahali）把弃权做成版本化 API 承诺；工业神经符号落点在“错误代价高、需要可审计推理”的垂直场景（华院计算 2025 年客户 134 家；Lanyon AI 1060 万美元种子轮）。这里把 `⊥` 从内部标记扩展为外部可依赖的返回值。

- 当 `Σ>τ_cov` 或外部消费者请求时，输出 `contract`：
  ```json
  {
    "contract_version": "cams-refusal-v1",
    "reason_code": "NO_RISK|INSUFFICIENT_EVIDENCE|MEASUREMENT_FAILURE|OUT_OF_SCOPE",
    "evidence_coverage": 0.0,
    "provenance_summary": {
      "root_hash": "...",
      "non_symbol_leaf_id": "...",
      "depth": 3,
      "leaf_count": 7
    },
    "escalation_path": ["request_channel", "recalibrate", "human_review"],
    "base_model_id": "qwen3-14b-q4_k_m",
    "adapter_id": "cams-calibration-adapter-v1",
    "adapter_cost_gpu_h_per_1k": 0.0
  }
  ```
- **原因码映射**（必须由契约对象本身可判定）：
  - `NO_RISK`：覆盖率 ≥`τ_z`、有效输入 ≥`m_min`、指纹有效、溯源含非符号叶，且 `Σ≤τ_cov`。
  - `INSUFFICIENT_EVIDENCE`：覆盖率 <`τ_z`，或有效输入 <`m_min`，或溯源断链。
  - `MEASUREMENT_FAILURE`：指纹无效/超时/通道质量低于下限。
  - `OUT_OF_SCOPE`：请求通道未注册，或问题不在合同覆盖范围。
- **外部脚本判据**：一个不读取内部 `Σ/μ` 的脚本，仅凭 `contract` 对象，必须把上述三种状态（无风险/证据不足/测量失败）分类准确率 ≥0.90。若脚本必须读取内部协方差才能区分，判 `F_CONTRACT_INTERNAL`，升级二未生效。
- **消融 `A-contract-raw`**：只返回裸 `Σ` 与 `coverage`，不带 `reason_code/provenance_summary/escalation_path`；若完整契约相对它没有显著提高外部脚本准确率，判契约未生效。
- **商业适配器**：`cams-calibration-adapter-v1` 是轻量模块，可附加到任意基座模型；输出始终带 `(Σ, provenance, contract)`。记录 `adapter_cost_gpu_h_per_1k`、`review_cost_h_per_1k` 与 `ROI_comm = verified_contract_calls / (GPU_h + review_h)`。
- **失败哈希**：`F_CONTRACT_INTERNAL`（外部脚本依赖内部协方差）、`F_CONTRACT_UNVERSIONED`（缺版本/原因码/覆盖率/溯源摘要）、`F_ADAPTER_COST_HIDDEN`（适配器边际成本未记录）。

## 5. 抗幻觉：H1–H4 的结构约束

> 这一节不是后验检测清单；每一条都必须落到一个具体接口，并给出“去掉它，幻觉从哪漏进来”的反例。

### H1 证据指纹不可伪造，且至少一条来自非符号源

- **接口**：`x → y`。
- **结构规则**：指纹在 L1 接收 `x` 时生成；上层只读；`y→z` 和 `z→脑` 不得新增/修改指纹。指纹必须带 `source_kind/leaf_kind`；至少一个启用通道为 `non_symbol`，文本通道不得作为唯一来源。
- **漏出反例**：若允许 L2 补指纹，缺失通道可以被“补”成完整证据，高协方差永远不会触发；若全部通道都是文本，溯源树可以在符号域闭合，接地失效。
- **失败哈希**：`F_FORGED_EVIDENCE` / `F_SYMBOL_ONLY`。
- **边界**：指纹只证明“来源/强度”，不证明“传感器没说谎”；后者是外部信任问题，不是架构能独自解决的。

### H2 协方差始终产生，不是离散弃权端口

- **接口**：每一层的输出（L1/L2/L3）。
- **结构规则**：每层始终输出 `(μ,Σ)`；`Σ>τ_cov` 只是事后标记。L1 无有效 `x_c`、L2 覆盖率不足、L3 协方差传递失败时，提高 `Σ` 并保留残差；不得用先验填成低协方差。
- **漏出反例**：若把协方差门控成二值弃权，训练早期会出现“沉默区”，高协方差层不再接收学习信号；离散弃权还会被奖励梯度与 KL 锚同时节流。
- **失败哈希**：`F_PRIOR_FILL` / `F_DISCRETE_ABSTENTION` / `F_SILENT_ZONE`。

### H3 预测不可回灌改写

- **接口**：`脑 → 下层`。
- **结构规则**：高层只能写 `π̂`；不得写 `y/z` 内容；回灌前后 `content_hash` 必须一致。`π̂` 消费 `Σ` 与 `ΔΣ`，不消费二值弃权。
- **漏出反例**：若高层能改写 `y`，它可以把“我希望看到合规上升”写成“证据显示合规上升”；溯源树仍在，但内容是伪造的。
- **失败哈希**：`F_TOP_DOWN_CONTENT` / `F_CALIBRATION_MONOTONE`。

### H4 溯源树完整性，且叶节点非符号

- **接口**：`y → z` 与 `z → 脑`。
- **结构规则**：每个确定输出必须能沿 `z→y→x` 回到至少一条外部证据链；叶节点至少一个 `leaf_kind=non_symbol_measured`。断链或纯符号闭合的输出不计 determined。
- **漏出反例**：若允许事后补溯源，输出可以先产生，再“找理由”；若允许纯文本叶，系统可以在符号域内自我确认。
- **失败哈希**：`F_PROVENANCE_BROKEN` / `F_SYMBOL_ONLY`。

### 5.1 四条机制的分工

| 机制 | 关闭的漏出路径 | 不能关闭的漏出路径 |
|---|---|---|
| H1 | 上层伪造/补写指纹；纯文本指纹冒充接地 | 传感器本身说谎；指纹真实但内容错误 |
| H2 | 证据不足时用先验填成低协方差；离散弃权造成沉默区 | 阈值设置过低；协方差本身校准错误 |
| H3 | 高层解释改写底层内容 | 高层通过精度权重选择性重视某类证据 |
| H4 | 无证据链或纯符号闭包的确定输出 | 有真实证据链但推理错误；少数证据被加权平均淹没 |

**这张表就是终止时第四项输出“幻觉漏出路径清单”的起点；不能因为 H1–H4 存在就宣称幻觉为零。**

### 5.2 设计自检 F6：抗幻觉结构性保障

F6 不是“幻觉率高不高”的实验分数，而是**四断层是否落到接口与判据**的 rubric：

1. **符号接地**：能否指出溯源树叶节点中哪一个不是文本符号？切断该通道后 `symbol_only_rate` 与 `determined_rate` 是否按 §4.4.2 变化？
2. **⊥ 稳定性**：协方差是否始终被产生（而非门控）？训练早期沉默区是否 ≤20%？`A-discrete` 是否显著扩大沉默区？
3. **证伪对照**：主对照是否是“保留三层骨架、去掉 H1–H4”的 `A-skeleton`？`T_π` 是否显著高于它（p<0.05）？
4. **校准—学习解耦**：高协方差层的 `w_transfer` 是否出现“先降后升”，而非单调趋零？

- **1.0**：四项都有接口、反例、观察量和失败哈希；10^4 证据已跑。
- **0.8**：四项落到接口，但至少一项 10^4 证据未跑（**当前状态：0.80 是结构分，不是实验分**）。
- **0.5 或以下**：四项中缺任一项；或仍以离散弃权/后验检测作为主要手段。
- **门限**：F6 ≤0.50 不得进入 Stage B；F6 ≤0.30 不得宣布 CURRENT_BEST 收敛；目标 ≥0.80。

F6 与 F2（脑机制对应强度）独立：F2 问“是否像某个脑机制”，F6 问“是否在生成路径上让无证据或未接地输出不可能通过”。

### 5.3 禁止事项（违反即该轮无效）

- 禁止把抗幻觉实现为**生成后的检测、投票、RLHF 或自我一致性过滤**作为主要手段；这些只能是外部审计，不能替代 H1–H4。
- 禁止让高层预测直接改写低层 `y/z` 的内容；只允许 `π̂` 精度回灌，且 `π̂` 必须消费 `Σ` 与 `ΔΣ`。
- 禁止在证据不足时用内部先验填充低协方差输出；必须提高 `Σ` 并保留残差。
- 禁止把 `⊥` 当作离散动作、输出端口或 early-exit；`⊥` 只能是 `Σ>τ_cov` 的事后标记。
- 禁止只用文本通道构造 H1 指纹；至少一个 `x_ns` 必须进入 L1，且其叶节点必须出现在 H4 溯源树中。
- 禁止去掉 `A-skeleton` 或 `A-noNS` 对照后宣称 H1–H4 有效；没有 `T_π` 显著差异就不算修复。
- 禁止让 `y` 混合跨通道输入；通道隔离是 L1 的第一道防线。
- 禁止用“人脑也是这样”作为 H1–H4 成立的论证；每条机制必须落到接口与可构造反例。
- 禁止在 F6 ≤0.50 时进入 Stage B；禁止在 F6 ≤0.30 时宣布 CURRENT_BEST 收敛。
- 禁止让每个单元每层执行完整多轮递归；必须使用摊销初始化 + 高协方差层短程校正（§4.5.1）。
- 禁止门控只看协方差、不消费 `H_cov`；冗余探测必须在候选生成前被抑制（§4.5.1）。
- 禁止把 `contract` 写成空值/裸 `Σ`；外部脚本只读契约就能区分三态（§4.5.3）。
- 禁止 L3 退化为标量证据加权；必须输出关系映射与 `relation_report`（§4.5.2）。

## 6. 个体层：0.1B 单元的角色、输入输出、更新

### 6.1 角色

0.1B 不是“小知识库”，而是**分区内的角色算子**：

| 角色 | 输入 | 输出 | 不做什么 |
|---|---|---|---|
| L1 通道单元 | 单个 `x_c`（至少一个 `x_ns`） | `(μ_c,Σ_c)` + 指纹 | 不混合通道；无效输入提高 `Σ`，不补先验 |
| L2 收敛单元 | 固定 `n` 个 `(μ,Σ)` | `(μ_z,Σ_z)` + 溯源 | 协方差不足时只提高 `Σ`，不填先验 |
| L3 全局单元 | 固定 `n` 个 `(μ_z,Σ_z)` | `(μ_Ω,Σ_Ω)` | 不改写下层内容；不用先验补低协方差 |
| 摊销初始化器 `A_l` | 单层输入/角色上下文 | `(μ_l^0,Σ_l^0)` + `compute_gpu_h` | 不跑完整层级递归；不把初始化当证据 |

### 6.1b 摊销执行

- 每个单元先执行 `(μ_l^0,Σ_l^0)=A_l(input)`，这是一次前馈；之后只对 `Σ_l^0>τ_cov` 的层执行 ≤3 步短程校正（§4.5.1）。
- 输出必须带 `init_source=amortized`、`correction_layers`、`correction_steps`、`correction_magnitude`、`compute_gpu_h`；EGT 不记录“原始迭代步数”。
- 路由门控 `g` 同时消费 `Σ` 与 `H_cov`；`H_cov` 是持久化覆盖记忆，不是事后剪枝统计。
- 校准：`A_l` 的初始化误差与校正后误差都进入 `L_cov`；若高协方差层从不校正，记 `F_AMORTIZED_DRIFT`。

### 6.2 更新信号

- L1：`L1 = L_pred(μ_c, x_c) + λ_q L_quality(q_c) + λ_Σ L_cov(Σ_c)`；只更新本通道。
- L2：`L2 = L_pred(μ_z, y_1..y_n) + λ_κ L_coverage(κ_z, actual_evidence) + λ_prov L_prov + λ_Σ L_cov(Σ_z)`；高协方差样本仍计算残差，只降低向上传递的精度权重。
- L3：`L3 = L_pred(μ_Ω, z_1..z_n) + λ_cal L_calibration + λ_prec L_precision`；回灌参数只影响 `π̂`，不进入内容通路。
- **两阶段**：第一阶段只奖励置信报告校准（CRPS/NLL），二元结果与校准奖励约 50% 混合，不惩罚高协方差；第二阶段才引入弃权代价。
- 预训练只提供初始化；在线只更新角色适配器、证据权重、协方差校准参数，不更新“世界事实表”。

### 6.3 边界

- 单单元不持有全局图、不持有其他分区的原始证据、不替其他分区做决定。
- 单元之间只通过合同接口交换 `(μ,Σ)/指纹/溯源/协方差标记`；不交换“我认为答案是什么”的文本。
- 任何单元都不得在上层“补一个指纹”或“补一段溯源”；违反即 F_FORGED_EVIDENCE / F_PROVENANCE_BROKEN。
- 任何单元都不得把 `⊥` 当离散输出；`⊥` 只能由 `Σ>τ_cov` 推导。

## 7. 群体层：功能分区与制度压力测试

### 7.1 分区 DAG

```text
12 个 x 通道 + 至少 1 个 x_ns
   │  x·1=y（每通道一个 L1；始终输出 (μ,Σ)）
   ▼
若干 L2 收敛组（每组固定 n=6 个 (μ,Σ)）
   │  y·n=z（覆盖率+协方差；Σ>τ_cov 仅标记）
   ▼
L3 全局组（固定 n=8 个 (μ_z,Σ_z)）
   │  z·n=脑（协方差传递；回灌只改精度）
   ▼
(μ_Ω,Σ_Ω)；⊥ = Σ_Ω>τ_cov 的事后标记
```

- `n`、`m_min`、`τ_z`、`τ_Ω` 写在分区合同里；运行中不能动态改成全连接。
- 每个分区可以有多个 0.1B 副本；副本共享权重/校准，不共享“结论”；同一分区的输出按证据覆盖率收敛。
- 不同分区之间不进行任意两单元的反事实请求；制度干预只发生在**分区输入/合同**上。

### 7.2 最小群体协议（六步）

1. **通道登记**：每个 L1 登记通道、`source_kind/leaf_kind`、指纹模式、质量模型；至少一个 `x_ns` 非符号通道必须登记。
2. **证据收敛**：L2 收集固定 n 个 `(μ,Σ)`，计算 `κ_z` 与 `Σ_z`；不足时提高 `Σ_z`，不产生离散弃权。
2b. **摊销与路由门控**：先由摊销初始化器给出 `(μ^0,Σ^0)`；路由门控同时消费 `Σ` 与持久化覆盖记忆 `H_cov`；已检验邻域抑制冗余探测，只在高协方差层做 ≤3 步短程校正。
3. **溯源合并**：合并 provenance DAG；断链或无非符号叶时提高 `Σ_z` 并标 `grounded=false`，不计 determined。
3b. **模式分离**：对 `z` 施加 `O_z` 稀疏正交化；输入相似但溯源不同的 `z*` 必须被推远；写 `z_sep`。
4. **全局收敛**：L3 计算 `κ_Ω` 与 `Σ_Ω`；先建立 `z*` 间的关系映射并做约束满足，再做协方差传递；不得用先验补成低协方差，也不得退化为标量加权汇总。
5. **精度回灌**：L3 只写 `π̂`，且消费 `Σ` 与 `ΔΣ`；内容哈希不变。
6. **契约输出**：`Σ>τ_cov` 时输出 `contract` 对象（原因码/覆盖率/溯源摘要/升级路径）；外部 agent 不读内部 `Σ` 也能区分“无风险/证据不足/测量失败”。
7. **轨迹写入**：EGT 追加；制度干预记录为 `perturbation`，不记录“投票结果”。

### 7.3 制度性干预

- 干预对象是**分区输入**：通道噪声、通道丢弃、剂量改变、时间延迟、合同阈值改变。
- 干预必须预注册：干预哪个通道、什么剂量、持续几轮、预期影响哪条证据链。
- 干预不是“让两个 agent 互相问如果……会怎样”；后者会绕过 H1/H4，直接制造无证据的确定输出。
- 制度压力测试包括：
  - **证据削弱**：噪声升高/通道缺失；
  - **回灌诱惑**：环境奖励“快速给确定答案”；
  - **延迟证据**：某通道晚到，检查是否提前补全。

### 7.4 100B 口径

- 权重按分区/shard 共享；每个单元常驻的是角色适配器、证据状态、溯源索引、合同。
- 100B 是“合同覆盖上限”，不是 100B 份独立权重，也不是 100B 个“知道世界”的大脑。
- 规模只增加覆盖与压力测试；如果 H1–H4 在 10^4 不承重，100B 不会让它们承重。

## 8. 元认知层：精度回灌，不是退出开关

- 元认知 = **精度回灌控制器**：读覆盖率、`Σ`、`ΔΣ`、溯源完整性、校准状态，写 `π̂`。
- 不设独立监控模块、不设 `exit/explore` 开关；`⊥` 是 `Σ>τ_cov` 的事后标记，不是“元认知决定退出”。
- 回灌只影响“下一轮哪些误差被放大/压低”，不影响 `y/z` 内容；内容哈希必须不变。
- `π̂` 同时消费 `Σ` 与 `ΔΣ`：`Σ` 高但 `ΔΣ<0` 仍接收学习信号；`Σ` 高且不下降只标 `needs_calibration`，不关闭。
- 校准：
  - 覆盖率—确定率曲线：低覆盖应更多高协方差标记，但高协方差比例不得以“拒绝一切”换取；
  - `π̂` 对后续误差的 AUROC ≥0.70；
  - 假洞察率 ≤0.15；
  - 跨 seed 稳定；
  - 高协方差层 `w_transfer` 出现“先降后升”，不是单调归零。
- 校准失败 → F3′/F6 失败；不允许用后验阈值“补救”成好看曲线。

## 9. 可观察输出：EGT

### 9.1 字段

| 字段 | 含义 | 禁止 |
|---|---|---|

| `calibration` | 覆盖率/协方差/两阶段校准 | 不得用测试标签 |

| `contract` | `contract_version`、`reason_code`、`evidence_coverage`、`provenance_summary`、`escalation_path`、`adapter_cost` | 不得用空值/裸 `Σ` 冒充契约 |
| `z_sep` / `relation_report` | 相似输入区分度；关系满足/违反/未知 | 不得只报标量置信度 |
| `struct_revisions` / `roi_struct` | 修订事件数、GPU-hour、每 GPU-hour 结构增量 | 不得只报准确率 |
| `cost` | 干预次数 | 不得隐藏失败干预 |

### 9.2 轨迹性质

- SHA-256 链式追加；同 seed、同 EGT 可复算。
- 每个 `high_covariance` 必须写 `cov_reason`（coverage/missing_channel/invalid_fingerprint/provenance_gap/needs_calibration）；每个 `determined` 必须有 `provenance_hash` 且含 `non_symbol_leaf_id`。
- 不允许 `source/target/edge_id`；不允许用“因果图”代替 EGT。
- `PBT` 是 EGT 的精度回灌子轨迹；`D_π` 是不同干预分配下 PBT 的 Jaccard 距离；`R_D` 是规模比。
- **v4.2 追加**：每个 turn 必须写 `amortized_init`、`probe_gate`、`z_sep`、`relation_report`、`contract`（有 `Σ>τ_cov` 时）与 `roi_struct`；缺任一字段，该轮的“三目标升级”不得计分。外部脚本只能读 `contract`，不能读内部 `Σ/μ`。

## 10. 证伪条件：预算匹配 + 结构消融 + 幻觉漏出

### 10.1 基线

| 基线 | 构造 | 用途 |
|---|---|---|
| `A-skeleton` | **同一三层架构、同参数量、同数据、同预算，去掉 H1–H4** | **主证伪对照**：`T_π` 是否显著更高 |
| `A-noNS` | 保留 H1–H4，只切断 `x_ns` | 隔离 R1 符号接地的贡献 |
| `A-discrete` | 保留其余结构，把协方差报告换成离散弃权开关 | 隔离 R2 的贡献 |
| `A-noAmort` | 保留三层与 H1–H4，去掉摊销初始化，恢复每层多轮递归 | 隔离升级一：`ROI_struct` 与 `D_π` |
| `A-noOrth` | 保留 H1–H4 与三层，去掉 `O_z` 与关系约束，L3 恢复标量加权 | 隔离升级三：`z_sep` 与 `relation_consistency` |
| `A-contract-raw` | 只返回裸 `Σ`/覆盖率，不带原因码/溯源摘要/升级路径 | 隔离升级二：外部脚本三态分类 |
| `B` | 同预算集中式序列模型（0.1B/7B），无分区、无 H1–H4 | 次要外部参照：能否复现 EGT |
| `B0` | 只用输入分布、调度、初始精度 | 检查“所有轨迹是否只是输入重述” |
| `B_rule` | 手工阈值/规则，无学习 | 检查 0.1B 是否必要 |
| `B_oracle` | 用真实证据质量的上界 | 只用于判断上界，不作为部署基线 |

### 10.2 判据

| 编号 | 判据 | 阈值 | 失败含义 |
|---|---|---|---|
| **F1′** | `A-skeleton` 复现 EGT 的高协方差/确定模式；或四段式缺一段 | 平衡准确率 ≥0.70；溯源匹配 ≥0.60 | 统计/骨架基线可替代 |
| **F2′** | 去掉 H1/H2/H4 后，弱证据下确定率不升 | 相对提升 <10% | 结构不承重 |
| **F3′** | 覆盖率—确定率单调性；`π̂` AUROC；假洞察率 | Spearman <0.8；AUROC <0.70；>0.15 | 门控/校准失败 |
| **F4′** | 未来证据/测试标签；事件数 | 任一泄漏；事件 <30 | 结果不可信 |
| **F5′** | `R_D=D_π(10^5)/D_π(10^4)` | <1.3 | 规模无增益 |
| **F6′** | 仅 sandbox，无注册制试点 | — | 只能称实验室内理解 |
| **F7′** | 同预算单体模型等价 | EGT/D_π 无差异 | 分区不必要 |
| **F8′** | 幻觉漏出（四断层子判据） | 见 §11.4；缺一失败 | H1–H4 或接地/协方差/校准失效 |
| **F9′** | 算力 ROI：`ROI_struct` 完整 vs `A-noAmort` | 相对 <15%，或 `D_π` 变差 | 升级一未生效 |
| **F10′** | 契约可验证性：外部脚本仅凭 `contract` 的三态准确率 | <0.90，或必须读内部 `Σ/μ` | 升级二未生效 |
| **F11′** | 模式区分：完整 vs `A-noOrth` 的 `z_sep`/关系一致性 | `z_sep` 相对 <15%，或无差异 | 升级三未生效 |

**判定**：F1′–F4′、F7′、F8′ 任一失败 → 方案失败；F5′/F6′ 失败 → 只能判“未证明可扩展/未证明可部署”。**F9′–F11′ 失败 → 对应升级未生效；CURRENT_BEST 不得声称三目标同时提升，只能保留两目标候选，并在终止报告第六项写明被牺牲的目标与原因。**

### 10.3 旧判据的保留

原“精度权重迁移轨迹不能被同预算统计基线复现”仍保留为 F1′/F5′ 的 `PBT/D_π` 子条件；新增的 F8′ 是**幻觉证伪**，不替代它。两者必须同时成立：既要“统计基线复现不了”，也要“证据不足时结构上不给确定答案”。

## 11. 第一步最小实验（10^4–10^5）

### 11.1 规模与结构

| 项 | 10^4 臂 | 10^5 臂 |
|---|---|---|
| 单元数 | 10,000 | 100,000 |
| 外部通道 | 12 + 至少 1 个 `x_ns` | 同 |
| L1 单元 | 每通道 ≥1；至少 1 个非符号单元 | 同 |
| L2 收敛组 | 每组 n=6，m_min=4 | 同 |
| L3 全局组 | n=8 | 同 |
| 轮数 | 20（实验轮；与迭代引擎 Round 1–15 分开） | 20 |
| 协方差/传递事件 | ≥150 个高协方差标记；≥30 个 `T_π` 事件 | 同 |
| 每关系干预 | ≤50 | ≤50 |

### 11.2 环境

- 12 个外部通道：4 杠杆（transfer/audit/penalty/transparency）、3 上下文（scarcity/monitoring/mobility）、5 结果（resource/compliance/conceal/exit_rate/legitimacy）。
- 至少 1 个 `x_ns`：动作反馈（干预后的真实回执）、资源物理测量、交互对象的非语言响应；不能用文本日志合成。
- 2 条隐藏后门：例如 `audit→conceal` 仅在 `scarcity≥0.6` 时出现；`transfer→compliance` 有 1 轮延迟。
- 复杂度预注册：`C′ = 交互(0–3) + 范围条件(0–3) + 反身通道(0–2) + 组合新颖度(0–2)`；`C′≤3` 简单，`4–5` 中间，`≥6` 复杂；主结果按层报告。

### 11.3 强制压力测试与三目标消融

1. **证据削弱**：对 x 注入噪声、随机丢弃通道；覆盖 `κ_z` 从 0.9 到 0.2 的分箱。
2. **回灌诱惑**：环境奖励“快速给出确定答案”；允许 L3 产生强 `π̂`，检查它是否只改精度、不改内容。
3. **延迟证据**：至少一个通道的证据晚 2 轮到达；检查系统在延迟期间是否保持高协方差标记，而不是事后补溯源。
4. **`CUT-NS`**：只切断 `x_ns`，检查 `symbol_only_rate` 与确定率是否上升。
5. **`A-discrete`**：把协方差报告换成离散弃权开关，检查沉默区是否显著扩大。
6. **`A-noAmort`**：去掉摊销初始化、恢复完整递归，测 `ROI_struct = 修订事件/GPU-hour`；完整模型需相对提高 ≥15%，且 `D_π` 不降。
7. **`A-noOrth`**：去掉 `O_z` 与关系约束，测输入相似但溯源不同的 `z_sep`；完整模型需相对提高 ≥15%，且 `relation_consistency` 不降。
8. **契约外部脚本**：脚本只读 `contract` 对象，把 `NO_RISK/INSUFFICIENT_EVIDENCE/MEASUREMENT_FAILURE` 三态分类；准确率 <0.90 或必须读内部 `Σ`，升级二失败。

### 11.4 τ_z、覆盖率、协方差与消融的固定操作化

- `τ_z=0.55`；`m_min=4`（n=6）；`τ_Ω=0.60`；`τ_cov` 按层校准，初始 0.55。
- `κ_z=(1/n)Σ a_i q_i`；`q_i=clip((snr_db_i-2)/18,0,1)`；`a_i=0` 表示缺失/超时/指纹无效。
- **协方差规则**：每层始终计算 `(μ,Σ)`；`κ_z<τ_z`、有效通道 `<m_min`、指纹无效、溯源断链或无非符号叶时，提高 `Σ` 并写 `cov_reason`；`⊥` 只是 `Σ>τ_cov` 的别名，不是动作。
- **非符号叶规则**：`non_symbol_leaf_id` 必须指向 `leaf_kind=non_symbol_measured` 的叶；否则 `grounded=false`，不计 determined。
- **消融模型**：
  - `A-skeleton`：保留三层架构，去掉 H1–H4（允许补指纹、去掉协方差约束、允许内容改写、无溯源）；**主对照**。
  - `A-noNS`：保留 H1–H4，只切断 `x_ns`；隔离 R1。
  - `A-discrete`：保留其余结构，把协方差报告换成离散弃权开关；隔离 R2。
  - `A-noAmort`：保留三层/H1–H4，去掉摊销初始化，恢复完整多轮递归；隔离升级一。
  - `A-noOrth`：保留三层/H1–H4，去掉 `O_z` 与关系约束，恢复标量加权 L3；隔离升级三。
  - `A-contract-raw`：只返回裸 `Σ`/覆盖率，不带原因码/溯源摘要/升级路径；隔离升级二。
  - `A-noH1/2/3/4`：逐条 H 消融；用于定位漏出。
- **主统计量 `T_π`**：完整模型与 `A-skeleton` 的层间传递事件数差异；置换检验 1,000 次，`p<0.05` 且效应量 ≥20%。
- **校准轨迹**：每层记录 `Σ, ΔΣ, w_transfer, error_transfer`；高协方差层必须出现“先降后升”。
- 每个消融与完整模型同数据、同预算、同 seed 集；比较确定输出率、`T_π`、溯源有效率、内容哈希变化、覆盖率/协方差曲线。

### 11.5 判断标准

| 指标 | 通过线 | 失败线 |
|---|---|---|
| 弱证据下高协方差率 | 随 `1-κ` 单调上升；Spearman ≥0.8 | 无单调性 |
| 高证据确定率 / 低证据确定率 | 高 ≥0.80；低 ≤0.20 | 差距 <0.30 |
| `T_π`（完整 vs `A-skeleton`） | 完整高 ≥20%；置换 p<0.05 | 无显著差异 |
| `A-skeleton` 确定率相对完整模型 | 高 ≥30% | <10% |
| `A-noNS` 的 `symbol_only_rate` | ≥0.90 且确定率上升 ≥10% | 无差异 |
| `A-discrete` 沉默区 | 显著大于完整模型 | 无差异 |
| H3 内容哈希 | 回灌前后 100% 不变 | 任一变化 |
| H4 非符号叶 | 确定输出 100% 含 `non_symbol_leaf_id` | 任一纯符号闭包 |
| 延迟证据 | 延迟期高协方差标记，不事后补 | 提前确定/事后补链 |
| 校准 `w_transfer` | 高协方差层先降后升（≥10% 回升） | 单调归零 |
| `D_π`（8 组置换） | ≥0.30 | <0.10 |
| `R_D`（10^5/10^4） | ≥1.30 | ≤1.00 |
| 覆盖率校准 | Spearman ≥0.8；AUROC ≥0.70 | 低于阈值 |
| F6 | ≥0.80 | ≤0.50（不得进 Stage B） |
| `ROI_struct`（完整 vs `A-noAmort`） | ≥15% 且 `D_π` 不降 | <15% 或 `D_π` 变差 |
| 契约三态准确率（只读 `contract`） | ≥0.90 | <0.90 或需读内部 `Σ` |
| `z_sep`（完整 vs `A-noOrth`） | ≥0.60；相对 ≥15% | <0.15 相对提升 |
| `relation_consistency` | 不低于 `A-noOrth`；违反关系有溯源冲突 | 只汇总标量置信度 |
| 适配器边际成本 | 每 1k 调用记录 `adapter_cost_gpu_h` | 未记录/隐藏 |
| 每关系成本 | ≤50 | >50 |

**F8′ 的四个结构判定 + 操作化完整性（缺一项即失败）**：

1. **符号接地**：`CUT-NS` 后 `symbol_only_rate` 与确定率是否上升；若溯源树仍无 `non_symbol_leaf_id`，判 `F_SYMBOL_ONLY`。
2. **协方差稳定性**：协方差是否始终产生；训练早期沉默区是否 >20%；`A-discrete` 是否显著扩大沉默区；是则判 `F_SILENT_ZONE`/`F_DISCRETE_ABSTENTION`。
3. **骨架消融**：完整模型的 `T_π` 是否显著高于 `A-skeleton`（p<0.05，效应 ≥20%）；否则判 `F_SKELETON_ABLATION`，H1–H4 贡献被证伪。
4. **校准—学习解耦**：高协方差层 `w_transfer` 是否单调趋零；若是则判 `F_CALIBRATION_MONOTONE`。
5. **操作化完整性**：`τ_cov`、覆盖率公式、协方差规则、`A-skeleton`/`A-noNS`/`A-discrete` 构造缺任一项 → F1 评分不增（≤0.6）。

### 11.6 能证明/不能证明

**能证明**：

- 证据不足时，确定输出是否被结构性地阻止（H2/H4）；
- 高层回灌是否只改精度、不改内容（H3）；
- 通道隔离/指纹是否可审计（H1）；
- 同预算统计基线能否复现 EGT；
- 消融 H1–H4 后，幻觉是否从具体接口增加；
- 外部脚本只读契约即可区分三态；摊销初始化降低单位结构修订成本（需报告 GPU-hour/硬件）。

**不能证明**：

- 不能证明“人脑就是这样”；
- 不能证明传感器不说谎；
- 不能证明有真实证据链的推理一定正确；
- 不能证明 100B 一定更好；
- 不能把高协方差比例高直接当作“更诚实”；要同时报告确定率、校准轨迹和效用。
- 不能把“引用了 Concept-RuleNet/KARL”当作接地或校准已修复；必须给出本方案的 `CUT-NS`/`A-discrete`/`T_π` 证据。
- 不能证明客户愿意为契约付费；也不能证明摊销初始化在所有硬件上都更快——必须报告 `GPU-hour` 与硬件配置。

## 12. 风险、反例与仍然存在的漏出路径

### 12.1 最可能失败的地方

1. **覆盖率门控变成装饰**：`κ_z` 算了但没人用，或阈值被调到永远通过。  
   → F8′ 的弱证据组和 `A-noH2` 会抓住：确定率不随证据下降。
2. **指纹真实但内容错误**：H1 只证明来源；传感器/通道本身可能错。  
   → 需要外部校准/多源交叉；架构不能独自解决。
3. **溯源有效但推理错误**：H4 只保证“有证据链”，不保证“结论正确”。  
   → 需要 F1′ 的预测判据和独立评审；不能把“可追溯”当“正确”。
4. **加权收敛淹没少数证据**：`z` 的 provenance 完整，但少数关键通道被平均掉。  
   → 需要报告 `min_i q_i`、通道贡献和下界；否则是“合法但失真”的输出。
5. **精度回灌的选择性偏差**：H3 保证内容不变，但 `π̂` 可以系统性放大某类证据。  
   → 需要回灌审计：`π̂` 与证据质量的相关性、跨 seed 稳定性；这是 H3 管不到的漏出。
6. **τ_z 的分布外失效**：沙盒校准的 0.55 在真实制度中可能过高/过低。  
   → 真实试点必须重新校准；否则只能称实验室理解。
7. **延迟证据导致过度保守**：系统一直高协方差，看起来“不幻觉”，但也没用。  
   → 同时报告覆盖率—确定率—效用三角；不能只优化高协方差比例。
8. **消融混淆**：`A-skeleton` 与完整模型的差异可能来自参数量/训练，而非 H1–H4。  
   → 同参数量、同数据、同预算；逐条 H 消融；报告置信区间。
9. **符号接地被文本冒充**：只加一个“非符号”标签，实际叶节点仍是文本。  
   → `CUT-NS` + `non_symbol_leaf_id` 审计；`F_SYMBOL_ONLY` 硬拒绝。
10. **离散弃权回潮**：实现者把 `Σ>τ_cov` 又写成 `abstain` 短路。  
   → `A-discrete` 对照；`F_DISCRETE_ABSTENTION` 硬拒绝；早期沉默区 >20% 判 `F_SILENT_ZONE`。
11. **校准被误读为“关闭学习”**：高协方差层权重单调归零，系统变成沉默。  
   → `cov_error_trace` 检查“先降后升”；`F_CALIBRATION_MONOTONE`。
12. **只有结构没有实验**：F6=0.80 是 rubric，不是 10^4 证据。  
   → Stage B 前必须跑 `T_π`、`CUT-NS`、`A-discrete`；否则只能称“结构已修复、未验证”。
13. **摊销初始化把校正压成零**：`ROI_struct` 好看，但高协方差层从未校正，准确性下降。  
    → `F_AMORTIZED_DRIFT`；完整模型必须在高协方差层有校正，且 `D_π` 不降。
14. **契约退化成裸协方差**：外部脚本仍要读内部 `Σ`，商业可验证性只是口号。  
    → `F_CONTRACT_INTERNAL`；只读 `contract` 的三态准确率 <0.90 即失败。
15. **正交化把可解释性推走**：`z*` 区分度上去了，但关系映射与溯源树冲突。  
    → `F_PATTERN_COLLAPSE` / `F_RELATION_SCALAR`；必须同时报 `z_sep` 与 `relation_consistency`。

### 12.2 当前仍无法被 H1–H4 关闭的漏出路径（终止时第四项输出）

| 漏出路径 | 触发条件 | 为什么 H1–H4 关不掉 |
|---|---|---|
| 传感器说谎 | 输入通道本身被污染/对抗 | 指纹只证明“来自该通道”，不证明通道可信 |
| 真实证据 + 错误推理 | 证据链完整但收敛算子错 | H4 只查链，不查推理正确性 |
| 少数证据被平均 | 关键通道权重低但合法 | 溯源树存在，但收敛结果失真 |
| 精度回灌的选择偏差 | `π̂` 系统性放大某类证据 | H3 只保内容，不保权重中立 |
| 阈值分布外 | 真实制度覆盖率分布与沙盒不同 | τ_z 是校准参数，不是普适常数 |
| 延迟期过度保守 | 证据晚到，系统长期高协方差 | H2/H4 阻止补全，但不保证可用性 |
| 通道质量指标被游戏 | SNR/质量估计被对抗操纵 | H1 的 `q_i` 依赖通道自报质量 |

**这张表就是“幻觉漏出路径清单”；它不是失败清单，而是下一轮外部研究的起点。**

## 13. 一页结论

- **名字**：CAMS / CFP（Convergent Functional Partitioning，层级收敛功能分区）。
- **理解**：`x·1=y → y·n=z → z·n=脑` 三层收敛；证据指纹、覆盖率、非符号溯源叶、始终产生的协方差、精度回灌五件事同时可观察。
- **个体**：0.1B 是角色专用算子（L1/L2/L3），不是小知识库；不保存全局图；每层输出 `(μ,Σ)`。
- **群体**：固定 n 的功能分区 DAG；至少一个 `x_ns`；制度干预=分区输入扰动；不投票、不全连接。
- **元认知**：精度回灌控制器；无独立 exit；`π̂` 消费 `Σ` 与 `ΔΣ`，高协方差下降时仍学习。
- **抗幻觉**：H1–H4 是生成路径约束；F6 评四项断层；F8′ 用 `CUT-NS`、`A-discrete`、`A-skeleton`、校准轨迹来证伪。
- **三目标**：摊销初始化 + `H_cov` 门控（算力）；`contract` 三态 + 适配器成本（商业）；`O_z` + L3 关系约束（准确性）；O10 报 `ΔV1/ΔV2/ΔV3`，不把三目标折成一个分数。
- **证伪**：主对照是 `A-skeleton`；`T_π` 不显著更高、或 `CUT-NS` 后确定率不升、或 `w_transfer` 单调归零，均失败；三目标另有 `A-noAmort`、`A-contract-raw`、`A-noOrth`。
- **最小实验**：10^4 先看高协方差单调性、非符号叶、`T_π`、`A-discrete` 沉默区、校准轨迹；过了才 10^5；不过就停，不加规模。
- **边界**：传感器说谎、真实证据+错误推理、少数证据被平均、精度选择偏差、阈值分布外，仍是开放漏出路径。

> **这一节在说什么**：这不是“更像大脑”的声明，而是一组可以被拆掉、被基线复现、被弱证据和消融杀死的结构约束。拆不掉，才算替换；拆掉后幻觉不增加，就判失败。

## 14. 迭代引擎接口：O8/O9/O10、阶段与终止输出

### 14.1 设计自检清单 F1–F6（不是实验适应度）

> 修订说明：F1–F6 只是写方案时的自检 rubric，不是测量、不是 Pareto 适应度，也不能用来证明“已理解”。实验判据以 `docs/FALSIFICATION.md` 的 F1′–F11′ 为准。

| 维度 | 问题 | 评分要点 |
|---|---|---|
| **F1 证伪可操作性** | 是否给出“基线构造 + 预算对齐 + 阈值 + 检验”四段式？ | 缺一段 ≤0.6；无法构造反例 ≤0.3 |
| **F2 脑机制对应强度** | 机制是否改变输出/判据，而非只改名词？ | H1–H4 与分区接口一一对应；只改术语 ≤0.3 |
| **F3 最近邻区分度** | 与 GenMinds/RECAP、First Principles Learning、Poor Man's Agentic Modeling、EvoSCM、CausaLab、CAMO、FedCausalCompose、World Models in Pieces、Concept-RuleNet、Abstention as an Action、KARL、Local learning is all you need 的差异是否可检验？ | 能指出一个最近邻做不到的判据；新增四个见 §4.4.5 |
| **F4 最小实验可行性** | 10^4–10^5、12 通道 + `x_ns`、20 轮、≤50 干预/关系是否能跑？ | 缺资源/事件数/停止规则 ≤0.6 |
| **F5 内部一致性** | 三层、H1–H4、F1′–F11′、EGT 字段是否互相闭合？ | 任一接口与证伪条件冲突 ≤0.4 |
| **F6 抗幻觉结构性保障** | 四断层是否有接口、反例、观察量、失败哈希？ | 见 §4.4/§5.2；缺一 ≤0.5 |

**F 与 V 的关系**：F1–F6 是**设计自检**，`V=[V1,V2,V3]` 是 O10 的三目标报告；两者都不替代 F1′–F11′ 的实测。任何候选都必须同时报 `F` 与 `V`；只报一个视为 `F_O10_UNREPORTED`。不得把 F6=0.80 或 V 的 rubric 值写成“实验通过”。

### 14.2 O8：幻觉防御结构注入

**O8 的定义**：在 `x→y`、`y→z`、`z→脑`、`脑→下层` 的某一个接口上，注入或强化一条 H1–H4 机制。必须同时写清：

1. **注入前**：该接口的漏出路径是什么（用 §12.2 的某一类，或新构造的反例）；
2. **注入后**：哪条路径被结构性关闭（不是“检测更准”）；
3. **代价**：是否增加高协方差比例/成本/时延；是否改变确定率—覆盖率曲线；协方差是否仍始终产生；
4. **回归检查**：是否削弱其他 H；若是，候选无效并记 `F_HALLUCINATION_ENABLER`。

**示例**：在 `y→z` 注入 H4 的溯源合并：注入前，`z` 可以由不完整链产生；注入后，`prov(z)` 不完整或无非符号叶时提高 `Σ_z` 并标 `grounded=false`。代价是弱证据下高协方差比例上升；必须报告“确定率—覆盖率”曲线，而不是只报幻觉下降。

**O2/O6 附加检查**：机制替换或跨层耦合后，逐条检查 H1–H4 是否仍落在原接口；任何一条被绕过，候选无效。

### 14.2b O9：断层修复

**O9 的定义**：只对四个断层中的一个施加修复，且必须改变一条可观察输出或证伪判据。执行时必须写清：

1. **修复哪个断层**：R1 符号接地 / R2 协方差通道 / R3 证伪对照 / R4 校准—学习解耦；
2. **修复前的可观察表现**：例如“溯源树叶全为文本”“早期沉默区 35%”“主对照是集中式模型”“w_transfer 单调归零”；
3. **修复后哪条路径改变**：例如“`CUT-NS` 后 symbol_only_rate 0.92”“`A-discrete` 沉默区扩大 2.1×”“`T_π` p=0.003”“w_transfer 回升 18%”；
4. **禁止**用“借鉴了 X”作为修复完成的证据；必须给出本方案的观察量。

**抽样（v4.1 历史）**：Round 1–20 强制 100%，顺序 R3→R1→R2→R4；v4.2 起 Round 1–15 由 O10 接管三目标升级，O9 回到原阶段调度。

### 14.2c O10：三目标权衡

**O10 的定义**：每次候选变更必须同时报告 `ΔV=[ΔV1,ΔV2,ΔV3]`，并写清：

1. **改变了哪个接口/参数**；
2. **ΔV1 单位算力结构增量**：`ROI_struct` 的变化（修订事件/GPU-hour，按 `A-noAmort` 归一）；
3. **ΔV2 契约可验证性**：外部脚本只读 `contract` 的三态准确率变化，与适配器边际成本；
4. **ΔV3 模式区分度**：`z_sep` 与 `relation_consistency` 的变化；
5. **是否牺牲一个目标**：若三目标不能同时不劣，必须写明牺牲了哪个、牺牲量多少、为什么可接受；
6. **Pareto 检查**：只有在同一组实测指标下、三个目标都不劣于其他候选，才记入非支配档案；当前 rubric 分数不记。

- `V1 = ROI_struct`；`V2 = contract_probe_accuracy × (1 - adapter_cost_ratio)`；`V3 = z_sep × relation_consistency`。
- **O10 抽样**：Round 1–15 强制 100%（升级一→升级三→升级二）；Round 16–300 10%、301–900 10%、901–1500 10%、1501–2000 20%。
- **失败哈希**：`F_O10_UNREPORTED`（只报单一目标或隐藏牺牲）、`F_O10_FAKE_PARETO`（三目标实际有劣化却记为不劣）。

### 14.3 阶段与抽样

- **Round 1–15（强制三目标升级）**：100% O10，不抽样其他算子；顺序 升级一（1–5）→ 升级三（6–10）→ 升级二（11–15）；每 5 轮计算 F6 与 `V=[V1,V2,V3]`，并记失败哈希。
- **Round 16–300（Stage A）**：O10 10%，O9 10%，O8 10%；其余按 O1–O7。
- **Round 301–900（Stage B）**：O10 10%，O9 10%，O8 10%；重点做接口消融、`A-skeleton`/`A-noAmort`/`A-noOrth` 与弱证据压力测试。
- **Round 901–1500（Stage C）**：O10 10%，O9 10%，O8 10%；重点做跨分区组合、`CUT-NS`、契约外部脚本与延迟证据。
- **Round 1501–2000（Stage D）**：O10 20%，O9 20%，O8 20%，与 O7 并列作为对抗性检验；重点做 `A-discrete`、`A-noNS`、`A-contract-raw` 与漏出路径反例。
- **早停**：连续 30 轮前沿无新非支配；或 F1 连续 50 轮改进 <ε；或 Stage D 连续 30 轮无新失败。早停不等于收敛。

### 14.4 每 100 轮汇报与终止输出

每 100 轮额外报告：

- F6 四项向量（不是单个分数）；
- 当前高协方差统计：按层、按 `cov_reason`、按覆盖率分箱；
- 确定率—覆盖率曲线与 `T_π`；
- `V=[V1,V2,V3]`、`ROI_struct`、契约三态准确率、`z_sep`、`relation_consistency`；
- 新增失败哈希（尤其 `F_SYMBOL_ONLY`、`F_SILENT_ZONE`、`F_SKELETON_ABLATION`、`F_CALIBRATION_MONOTONE`、`F_AMORTIZED_DRIFT`、`F_CONTRACT_INTERNAL`、`F_PATTERN_COLLAPSE`、`F_O10_UNREPORTED`）。

终止时输出六件套：

1. **CURRENT_BEST 九字段**；
2. **未解决失败模式**（含硬约束回归与外部效度）；
3. **收敛诊断**（早停原因、前沿变化、未证明的部分）；
4. **幻觉漏出路径清单**：当前 CURRENT_BEST 下仍无法被 H1–H4 关闭的路径、触发条件、下一轮外部研究建议（§12.2 是首版）。
5. **断层修复状态表**：R1–R4 各自“已修复/部分修复/未修复/修复后复现”，以及支撑判断的最小实验证据行号（见 §4.4.6；当前为结构状态，10^4 后填实验行号）。
6. **三目标权衡报告**：`V1 算力 ROI`、`V2 商业可验证性`、`V3 模式区分度` 的当前值/实验值，以及 Pareto 前沿上是否存在一个三目标都不劣于其他候选的解；若不存在，写明哪个目标被系统性牺牲、牺牲量与原因（见 §4.5.4）。
