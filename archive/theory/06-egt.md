# 06 — EGT: T5, T5′, and the 2000-round claim

> 问题：2000 轮 EGT 是否收敛？  
> 结论：不能从“2000 轮”推出收敛。有限状态 EGT 是 Markov 链；只有在不可约 + 非周期（或吸收结构）下才有收敛/吸收定理。无变异的确定性最优反应可以有 2-周期；2000 轮可能只是 1000 个周期。  
> v5.0 已不含 EGT；本文件把 2000 轮当 legacy 说法处理，不把它写成 v5.0 的定理。

## 1. 形式化

### 1.1 种群与策略

- 策略集 `S={1,...,k}`，`k<∞`。
- 种群规模 `N<∞`；状态是计数向量
  ```text
  n = (n_1,...,n_k) ∈ ℕ^k,  Σ_i n_i = N
  ```
  状态空间 `𝒩 = {n: Σ n_i=N}`，有限，大小 `C(N+k-1,k-1)`。
- 策略 `i` 的适应度 `f_i(n)`；可以是线性/非线性；本文件只要求 `f_i` 是 `n` 的确定性函数。
- 更新规则 `F: 𝒩→Δ(𝒩)`；若确定性，`F(n)∈𝒩`。常见：复制者动态、最优反应、logit/mutation。

### 1.2 Markov 链

若每轮只依赖当前 `n`，则 `n_t` 是有限状态 Markov 链，转移矩阵 `P(n'|n)=F(n)_{n'}`。`P` 是随机矩阵。

### 1.3 “收敛”的三种含义

1. **分布收敛**：`P^t(n,·) → π(·)`（总变差）。
2. **状态收敛**：`n_t → n*` 几乎必然。
3. **Cesàro/时间平均收敛**：`(1/T)Σ_{t=1}^T 1{n_t=n} → π(n)`。

三者不同。一个 2-周期链没有 1/2 的点态收敛，但时间平均可以收敛；把“平均频率稳定”写成“链收敛”是范畴错误。

## 2. T5 — 有限链收敛/周期定理

### 定理 T5（有限 EGT 链的收敛条件）

**假设**：
1. `𝒩` 有限；`P` 是 `𝒩` 上的 Markov 转移矩阵；
2. 要么 (a) `P` 不可约且非周期；要么 (b) `P` 有吸收态且从任意状态可达某个吸收态。

**结论**：
- (a) 存在唯一平稳分布 `π`，且对任意初始分布 `μ`，
  ```text
  ||μP^t - π||_TV → 0   (t→∞)
  ```
  收敛速率由第二个特征值/谱隙控制。
- (b) 链以概率 1 被某个吸收态吸收；吸收时间有限几乎必然，但期望可能很大。
- 若 `P` 可约或周期，上述分布收敛不一定成立；可能有多个平稳分布或周期轨道。

**证明（要点）**：
- 有限状态 + 不可约 + 非周期 ⇒ `P` 是本原随机矩阵；由 Perron–Frobenius 定理，特征值 1 单重，其余特征值模 <1；故 `P^t` 收敛到秩 1 的平稳投影。
- 吸收情形：有限链中到达吸收态的概率为 1（在可达假设下）；吸收态是闭类。
- 周期链：若周期 `d>1`，`P^d` 有多个闭类/特征值模 1，`P^t` 不收敛；只能得到 Cesàro 平均收敛。∎

**状态**：PROVEN（标准有限 Markov 链结论；不依赖 CAMS 细节）。

**So what**：
- “2000 轮”只有在链已混合（`t ≥ t_mix(ε)`）时才能近似平稳；`t_mix` 不由轮数本身给出。
- 若没有变异/噪声，最优反应动态可能是周期的；2000 轮不是收敛证据。
- 若要证收敛，必须证明不可约/非周期（或吸收）并给混合时间/谱隙；否则只能写 `[TBD]`。

**反例（证明失败的情形）**：若 `P` 可约且有两个闭类，`P^t` 依赖初始类，不收敛到唯一 `π`；若 `P` 周期，`P^t` 振荡。T5 的条件不是装饰。

## 3. T5′ — 2-周期反例

### 定理 T5′（2000 轮可以不收敛）

**假设**：
1. 两个策略 `A,B`；种群全部采用同一策略（纯状态 `A^N` 或 `B^N`）；
2. 收益矩阵（行=自己，列=对手）：
   ```text
        A    B
   A    0    1
   B    1    0
   ```
3. 每轮所有个体同时对对手的当前策略做最优反应（无变异、无噪声、无异步）。

**结论**：动态
```text
A^N → B^N → A^N → B^N → ...
```
是 2-周期；从 `A^N` 出发，`n_t` 永不收敛，`P^t` 不收敛到平稳分布。2000 轮后仍在 `A^N`（偶数轮）或 `B^N`（奇数轮），不是“收敛”。

**证明**：
- 若对手采用 `A`，选择 `B` 得 1，选择 `A` 得 0；最优反应是 `B`。
- 若对手采用 `B`，选择 `A` 得 1，选择 `B` 得 0；最优反应是 `A`。
- 所有个体同时更新，故 `A^N→B^N→A^N`；周期 2。∎

**状态**：PROVEN（构造性；同时更新、无变异）。

**So what**：
- 2000 是偶数，如果起点是 `A^N`，观测到的是 `A^N`；如果只看“结束时的状态等于初始状态”，会误以为“稳定”。必须检查周期/谱隙，而不是轮数。
- 若更新异步或有个体惯性，周期可能消失或变成混合；这需要另证，不能默认。
- 若加入变异 `ε>0`，链变为不可约/非周期（在适当条件下），T5(a) 可给出收敛；但平稳分布不一定是收益最大策略，且混合时间可能 ≫2000。

**反例（证明失败的情形）**：若收益矩阵是协调博弈（`A,A` 与 `B,B` 都高），最优反应可能锁定在某个纯策略，而不是 2-周期；T5′ 依赖反协调收益。这个反例说明“2-周期”不是所有 EGT 的宿命，但足以否定“2000 轮必然收敛”。

## 4. 2000 轮需要什么才能称“收敛”

至少需要以下之一：

1. **谱隙下界** `γ>0`，并给 `t_mix(ε) ≤ log(1/(επ_min))/γ`；证明 `2000 ≥ t_mix`。
2. **吸收时间界**：证明从任意初始状态在 2000 轮内到达吸收态的概率 ≥1-δ。
3. **单调势函数**：证明某 Lyapunov 函数每轮严格下降，且有下界；排除周期。
4. **时间平均结果**：只声称 Cesàro 平均收敛，不声称状态收敛；并明确这是弱结论。

没有这些，`2000 轮`只是运行长度，不是收敛定理。

## 5. 与 CAMS 的关系

- v5.0 没有 EGT；`2000 轮`是旧版 CFP 的说法，已被主文档降级/删除。
- 若未来要把 EGT 放回 CAMS，必须写清：
  - 策略/适应度/更新规则；
  - 变异/噪声；
  - 状态空间与转移核；
  - 收敛/周期的目标（分布/状态/时间平均）；
  - 混合时间/谱隙或吸收时间。
- 当前 `[TBD]`；不能把旧版的“2000 轮”当作 v5.0 的验证。

## 6. 红队路径（周期）

> 如果论文写“2000 轮 EGT 收敛”，T5′ 给出最小反例：反协调收益 + 同步最优反应 = 2-周期；2000 是偶数，结束时的状态看起来像初始状态。  
> 如果论文写“加变异就会收敛”，T5(a) 只给存在性/渐近性，不给 2000 轮的混合时间；需要谱隙下界。  
> 如果论文写“时间平均收敛”，那不是状态收敛；不能用来支撑“策略稳定/制度收敛”的强结论。

## 7. 一句话

> 2000 轮是预算，不是定理。收敛需要链结构（不可约/非周期/吸收）加混合时间界；没有这些，2-周期是最小反例。
