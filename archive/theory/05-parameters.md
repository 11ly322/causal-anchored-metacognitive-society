# 05 — Parameters: T4, T4′, T4″

> 问题：`τ_z=0.55`、`m_min=4` 是否最优？  
> 结论：在标准 0-1 决策模型下，最优阈值是后验的代价比，不是常数；`0.55` 只在特定代价/校准映射下最优。`m_min=4` 若被当作覆盖估计的最小样本量，在常见精度下远不够；若它是结构参数，则没有“最优”定理。  
> v5.0 的 `0.80/0.60` 同样是设计参数，不是定理。

## 1. 决策模型

### 1.1 二元状态

令 `G∈{0,1}`：`G=1` 表示 claim 为真/可接受，`G=0` 表示不可接受。审计器观察 `O`，有校准后验

```text
p = Pr[G=1 | O]
```

审计动作 `a∈{accept,reject}`。代价：

- `C_FP > 0`：接受一个 `G=0` 的代价（false positive / wrong accept）；
- `C_FN > 0`：拒绝一个 `G=1` 的代价（false negative / unnecessary abstention）。

期望代价：

```text
Cost(accept | p) = (1-p) C_FP
Cost(reject | p) = p C_FN
```

### 1.2 最优阈值

`accept` 优于 `reject` 当且仅当

```text
(1-p) C_FP ≤ p C_FN
⇔ p ≥ C_FP / (C_FP + C_FN)
```

记

```text
p* = C_FP / (C_FP + C_FN) = 1 / (1 + C_FN/C_FP)
```

这是**逐点最优**：对每个 `O`，选择期望代价更小的动作。它不依赖 `O` 的分布，只依赖校准后的 `p` 与代价。

## 2. T4 — 最优阈值定理

### 定理 T4（贝叶斯接受阈值）

**假设**：
1. `G∈{0,1}`，`p=Pr[G=1|O]` 是校准后验；
2. 代价 `C_FP,C_FN>0`，期望代价如上；
3. 决策只基于 `p`（不限制 `p` 如何从 `O` 得到）；
4. 允许随机化，但随机化不优于逐点最小代价。

**结论**：
```text
accept 是最优动作 ⇔ p ≥ p* = C_FP/(C_FP+C_FN)
```
且该阈值在所有可测决策规则中逐点最优；若 `p<p*`，`reject` 最优。

**证明**：
- 对固定 `p`，`accept` 与 `reject` 的期望代价差为
  ```text
  Cost(accept)-Cost(reject) = (1-p)C_FP - p C_FN
  ```
  这是 `p` 的线性函数；令其 ≤0 得 `p ≥ C_FP/(C_FP+C_FN)`。
- 由于期望代价对动作是线性的，逐点选择较小代价的动作在所有决策规则中最小化总期望代价；随机化是两个动作的凸组合，不会低于较小者。∎

**状态**：PROVEN（标准贝叶斯决策；条件 1 的“校准”是关键）。

**So what**：
- 不存在“分布-free 的最优常数阈值”；最优阈值由 `C_FP/C_FN` 决定。
- 若 `C_FP=C_FN`，`p*=0.5`；若 `C_FP=4C_FN`，`p*=0.8`；若 `C_FP=1.222C_FN`，`p*≈0.55`。
- 任何把 `0.55` 写成“最优”的句子，必须同时写 `C_FP/(C_FP+C_FN)=0.55` 或等价的代价比；否则是 `CONJECTURE`/错标。

**反例（证明失败的情形）**：若 `p` 未校准（例如模型 softmax 不是后验），T4 的假设 1 失败；此时 `p*` 不是最优阈值，需要校准或重新定义 `p`。这不是 T4 的反例，是适用条件失败。

## 3. T4′ — 0.55 不是普遍最优

### 定理 T4′（常数阈值无普遍最优性）

**假设**：
1. 对任意 `τ∈(0,1)`，允许选择代价 `C_FP,C_FN>0`；
2. 后验 `p` 可被校准到任意值（或至少存在一个 `O` 使 `p=τ`）；
3. 决策模型同 T4。

**结论**：对任意 `τ∈(0,1)`，存在代价使 `τ` 是最优阈值；不存在一个与代价/分布无关的“最优常数” `0.55`。具体地：

```text
τ 最优 ⇔ C_FP/(C_FP+C_FN)=τ
⇔ C_FN/C_FP = (1-τ)/τ
```

对 `τ=0.55`：
```text
C_FN/C_FP = 0.45/0.55 ≈ 0.818
⇔ C_FP ≈ 1.222 C_FN
```

**证明**：
- 给定 `τ`，取 `C_FP=τ`, `C_FN=1-τ`，则 `C_FP/(C_FP+C_FN)=τ`。由 T4，`τ` 最优。
- 取 `τ'≠τ`，则由 T4，`τ` 不是该代价下的最优阈值；故无普遍最优常数。∎

**状态**：PROVEN（构造性）。

**So what**：
- `0.55` 的适用条件不是“CAMS 的架构”，而是“假阳代价约为假阴代价的 1.22 倍 + 后验已校准”。
- 若实际代价比不是 1.222，`0.55` 是次优；若 `p` 未校准，连“阈值”都没有意义。
- v5.0 的 `0.80` 若被解释为后验阈值，则对应 `C_FP/C_FN=4`；若被解释为 coverage 阈值，则不是同一个量，不能套 T4。

**反例（证明失败的情形）**：若 `τ_z` 不是后验阈值，而是 L2 的收敛阈值/覆盖率阈值，则 T4′ 的映射不成立；此时 `0.55` 的“最优”没有定义，必须写 `[TBD]` 或给出 `φ: coverage→posterior` 的校准映射。

## 4. T4″ — m_min=4 的样本量问题

### 4.1 如果 `m_min` 是“独立回执/样本数”

设真实覆盖率 `p∈(0,1)`，用 `n` 个独立回执估计 `p`，要求误差 `ε`、置信度 `1-α`。Hoeffding 下界：

```text
n ≥ ln(2/α) / (2 ε²)
```

例如 `α=0.05, ε=0.10`：
```text
n ≥ ln(40)/(0.02) ≈ 3.689/0.02 ≈ 184.4 → n≥185
```

若用正态近似 `n ≥ z_{1-α/2}² p(1-p)/ε²`，`p=0.5, ε=0.1, 95%`：
```text
n ≥ 1.96² × 0.25 / 0.01 ≈ 96.04 → n≥97
```

`n=4` 时，正态近似的半宽约 `1.96×0.5/2 = 0.49`；即只能分辨约 ±49 个百分点的覆盖率，远不能支持 0.80/0.55 这种细阈值。

### 定理 T4″（4 不是一般充分的覆盖样本量）

**假设**：
1. `m_min` 被解释为独立回执/样本数；
2. 要求覆盖率估计误差 `ε≤0.10`、置信度 `≥0.95`；
3. 使用 Hoeffding 或正态近似作为下界（任一）。

**结论**：`m_min=4` 不满足该要求；在 `p=0.5` 附近，至少需要约 97（正态）到 185（Hoeffding）个样本。

**证明**：代入上式；4 远小于 97/185。∎

**状态**：PROVEN（在解释 1 与统计假设下）。

**So what**：
- 若 `m_min=4` 是“最少 4 个收敛单元/结构单元”，它不是样本量，T4″ 不适用；必须改名为结构参数，并声明“不提供覆盖率置信保证”。
- 若它被用来声称“4 个回执足够决定 coverage≥0.80”，该声称在统计上不成立。
- 任何 `m_min` 的“最优”都需要给出目标误差/置信度/分布；没有这些，`[TBD]`。

**反例（证明失败的情形）**：若 `m_min` 是确定性结构约束（例如 L2 至少 4 个单元才能形成关系图），它不是统计样本量；T4″ 的前提 1 失败。此时 `m_min=4` 是设计选择，不是统计最优。

## 5. 对 v5.0 的 `0.80/0.60` 的说明

- `coverage ≥0.80` 是**覆盖率**阈值，不是后验阈值；T4 不能直接套。只有当存在校准映射 `p=φ(cov)` 且 `φ(0.80)=C_FP/(C_FP+C_FN)` 时，0.80 才是该代价下的最优 coverage 阈值。
- `covariance ≤0.60` 是**不确定性**阈值；它的最优值取决于 `κ` 的尺度、代价、以及 `κ` 与真实错误率的关系。v5.0 没有给出 `κ` 的校准定理；0.60 是设计参数，`[TBD]`。
- 本文件不证明 0.80/0.60 最优；只给出“若要主张最优，必须补什么”。

## 6. 红队路径（参数任意）

> 如果论文的主结论是“0.55/4 最优”，T4′/T4″ 直接给出反例族/下界；主结论应降为“在特定代价比与样本量下的设计选择”。  
> 如果论文的主结论是“0.80 coverage 最优”，必须给出 `φ` 与代价比；否则它只是阈值。  
> 如果 `m_min` 被用作“4 个回执足够”的统计声明，T4″ 说明它不够；如果它是结构参数，就不能借用统计最优性的语言。

## 7. 一句话

> 阈值不是架构的属性，是代价、先验、校准和样本量的函数。把 `0.55`/`4` 写成“CAMS 的最优参数”，是把决策论问题误写成架构定理。
