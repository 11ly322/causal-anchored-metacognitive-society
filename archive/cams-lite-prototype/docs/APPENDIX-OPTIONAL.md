# APPENDIX-OPTIONAL — three-layer partition (optional)

> 这是可选的实现说明，不进入主 claim，不是 0.1B 训练方案，也不含政治管理叙事。

若要把审计层放在一个分层生成器外面，可用三层分区作为实现选择：

```text
x·1 = y       # 通道隔离：每个输入通道单独编码，保留非文本回执
y·n = z       # 固定 n 个收敛单元：覆盖率门控，输出 z 或 ⊥ 标记
z·n = 脑      # 关系约束：在 z 之间检查 depends_on / precedes / scope_includes
```

- 每层始终输出分布；`⊥` 只在 `covariance > τ_cov` 时作为事后标记。
- 回灌只改精度权重，不改写低层内容。
- 任何“确定”输出必须带溯源树摘要。
- 这是架构选项，不是实验结论；没有 10³/10⁴ 数据前不声称它优于基线。

主文档只把这一节当作可选实现，不作为 H1 的承重结构。
